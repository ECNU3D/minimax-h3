# H3 视频编辑与迁移模式

> H3 能把**已有视频**当输入做精准编辑与能力迁移，这是它区别于纯生成模型的核心能力。

## 1. 先确认能不能走编辑模式

**硬性前提（超了就先切素材）：**

- 输入视频 ≤ 3 段，**单段 2-15 秒，总时长 ≤ 15 秒**——原片超过 15 秒必须先剪出要改的那一段。
- 单个视频 ≤ 50 MB，格式 H.264/AVC 或 H.265/HEVC，内嵌音频 AAC/MP3。
- 音频参考 ≤ 3 段，单段 2-15 秒，**必须和图片或视频一起传，不能单独传音频**。
- 图 + 视频 + 音频 合计 ≤ 12 个文件。

**该走编辑模式的信号：**

| 用户说的 | 走编辑模式 |
|---------|-----------|
| 「这条素材别的都好，就是 XX 不对」 | ✅ 局部改，比重抽稳 |
| 「换个背景 / 改成夜景 / 去掉绿幕」 | ✅ |
| 「把里面的人换成 XX」「加一个人」「去掉墨镜」 | ✅ |
| 「台词说错了，换一句」「换个音色」 | ✅ |
| 「批量把画面里的产品换成客户的」 | ✅ 品牌植入，一条指令可改多处 |
| 「整体感觉不对，重来」 | ❌ 回生成模式重写提示词 |
| 「人物长相/身份要换成完全另一个人」 | ⚠️ 可做，但脸部一致性风险高，优先重生成 |

## 2. 编辑指令三段式

手册里成功率最高的编辑提示词都是这三段，**顺序不要反**——先说保住什么，再说改什么，最后说怎么融合。

```
【① 保留声明】保持@视频1 中的 XX、YY 和整体 ZZ 不变。
【② 修改点清单】仅将 …… 改为 ……；将 …… 替换为 ……；去掉 ……；在 …… 增加 ……。
【③ 融合约束】新元素的透视/光影/景深/运动需与原画面 ……，确保无缝融合。
```

**定位词是编辑模式的命门。** H3 靠空间词 + 时间词 + 特征词锁定要改的对象，写不准就改错东西：

- 空间：`画面左边` · `最后面的小孩` · `最左边小孩` · `人物所坐的椅子` · `人物从怀里拿出的照片`
- 时间：`视频开头出现的易拉罐` · `视频结尾塑料袋中的所有零食`
- 特征：`背景中原本发光的"全家"便利店招牌` · `原本佩戴的墨镜`

**多处修改可以一条指令并列**（手册验证过 6 处并列）：

```
将参考视频中的报纸替换为一本绿色封皮的书；人物所坐的椅子改为红色沙发；去掉人物佩戴的墨镜，
保留清晰面部；移除汽车燃烧效果，使车辆保持正常状态；人物从怀里拿出的照片改为一个黑色小本子；
同时在画面左侧增加一棵树
```

## 3. 六锁清单

替换背景、场景、大面积元素时，**必须逐条写死这六把锁**，否则新元素会和原画面「贴」在一起而不是「融」进去。手册原文（机械臂换办公室背景）已经把六锁写全，可直接当模板：

| 锁 | 手册原文 |
|----|---------|
| **透视比例锁** | `新办公桌的透视比例需与原镜头完全匹配` |
| **光影方向锁** | `桌面材质需自然承接原视频的光影投射，边缘阴影与高光方向必须与原场景光源严格一致` |
| **景深焦点锁** | `背景百叶窗与文件柜的景深虚化程度需与原视频焦点对齐，保持原有空间纵深感` |
| **运镜轨迹锁** | `原视频的镜头运动轨迹……必须保持 100% 不变` |
| **运动时序锁** | `机械臂的完整运动时序与速度……必须保持 100% 不变` |
| **遮挡关系锁** | `画面中其他物品的相对位置与空间遮挡关系、以及整体光照氛围必须保持 100% 不变` |

收尾统一写：`确保替换元素与原画面无缝融合。`

**绿幕合成还有第七条**——人物光线要反向匹配新背景：

```
将@视频1绿幕背景去除，变成类似@视频2的童话感背景，背景元素需要完全匹配@视频1的人物动作。
修改@视频1的人物光线，使之完全匹配背景。
```

## 4. 编辑类型与写法

### 4A. 角色与物体编辑

最简写法就能work，简单替换不要过度描述：

```
把@视频1中的猫换成狗
```

带图锚的精准替换（**用图片指定替换后的样子**）：

```
@视频1中最后面的小孩换成@图1中的金毛狗，@视频1中最左边小孩穿的卡其色外套改成@图2中的牛仔外套
```

增加人物（**必须写动作一致性**，否则新增的人会各演各的）：

```
画面左边增加一个穿着相同团队制服的人，动作与旁人保持一致
```

### 4B. 场景与背景替换

窗外换景：

```
@视频1窗外的场景改成@图1
```

完整六锁版见第 3 节。

### 4C. 光影与时间改写

```
参考@视频1，改变光照，改成夜晚
```

改时间/天气时，记得连带写反射与色温——原片里的高光、水面反光、肤色都要跟着变，不写模型容易只压暗不换光。

### 4D. 局部风格化（真实与风格化共存）

难点是**只风格化一部分、其余保持真实**，要正反双写：

```
保持@视频1中的建筑、行人和整体环境为真实世界风格不变。仅将@视频1画面中的树木、轿车转化为
3D 像素或体素积木风格 (Minecraft style)，风格参考@图1。像素化物体的运动轨迹需正常，
且保留真实环境的阴影和透射光。整体效果参考@视频2。
```

要点：①正面说保真的是什么 ②`仅将` 限定改的是什么 ③风格挂图锚 ④**运动轨迹需正常**（风格化后容易运动崩坏）⑤保留原环境阴影与透射光 ⑥整体效果再挂一条视频锚。

### 4E. 特效叠加（含渐进式）

特效可以绑定剧情节点做强度变化：

```
在@视频1中两个人周围加上@图1 这种橙黄色的手绘涂鸦，随着@视频1中两人靠近，手绘涂鸦越来越多，
从小的火花变成很明亮的光芒，在@视频1中两个人亲吻时，手绘涂鸦出现粉红色的笔触
```

要点：**特效强度绑到画面里的可见事件**（靠近 → 变多；亲吻 → 变色），比写「逐渐增强」精确得多。

### 4F. 台词与音色替换

```
将@视频1女生说的话："我们之间不可能在一起的，不是不爱，是我们真的走不到最后的"，
改成@音频1的台词："别走了，好吗？这一次，我们不要放开彼此"，并略微调整对应的表演
```

要点：①**原台词要抄全**，靠原文定位要替换的那一句 ②新台词写全 ③补 `并略微调整对应的表演`，让口型和表情跟着改，不然会出现口型对不上的鬼畜感。

**新旧台词字数要接近**——原句 24 字、新句 15 字，口型区间对不齐。按 `可容纳字数 ≈ (窗口秒数 − 0.4) × 4.5` 核一遍。

### 4G. 品牌植入（一条指令批量替换）

```
参考@视频1，将视频开头出现的易拉罐饮料替换为可口可乐；背景中原本发光的"全家"便利店招牌
修改为"互惠"招牌；视频结尾塑料袋中的所有零食也统一替换为可口可乐易拉罐，
最后结尾人物的台词从"买了一些小零食"变成了"买了一堆可乐"
```

要点：画面替换 + 招牌文字替换 + 台词替换可以**在一条指令里一起做**。
⚠️ 品牌包装的商标、字体、配色必须挂参考图（`替换为@图1中的易拉罐`），只写品牌名模型会自己画一个像但不对的包装——**这类素材一定要逐帧核商标**。

## 5. 迁移类型与写法

迁移 = 把参考素材的某一个维度（动作/运镜/节奏/音色）搬到新内容上，其余不搬。**写法关键是点名搬哪一维**。

### 5A. 动作与表演迁移

```
@图1的人物动作、表情与表演节奏严格参考@视频1。
男生站在画面中右侧的水槽前把洗好的盘子递给画面左侧的女生，随后转身突然用右手向画面左侧
边缘的女生甩出洗洁精泡沫。女生受到惊吓后立刻反击，两人开始开心地互相向对方泼洒泡沫并闪躲，伴随着大笑
```

要点：**挂了动作参考视频，仍然要把动作用文字写一遍**。参考视频管「怎么动」，文字管「动什么」。

跨物种动作模仿（把人换成动物还要严格复刻轨迹）：

```
参考@视频1进行动作模仿。固定机位全景镜头，原视频中三个穿西装的男人替换为三只高度写实的水豚。
水豚必须严格遵循原视频的运动轨迹：依次迅速趴到地板上，然后最左边的水豚跳到中间位置，
中间位置的水豚翻滚到最左边，接着中间的水豚翻滚到最右边，最右边的水豚跳跃到中间，
最后中间水豚跳跃到另外两只背上，堆叠成金字塔形状。保持原有的固定机位不变。
确保水豚的毛发质感和光影与环境融合
```

要点：轨迹要**逐步写成有序文字**（依次→然后→接着→最后），并补机位锁和材质融合句。

### 5B. 运镜迁移

```
参考@视频1的希区柯克镜头运动，让@视频2中的人物唱歌，歌声和唱歌表演参考@视频3
```

这条同时用了 3 段视频，各管一维：视频1 管运镜、视频2 管人物、视频3 管歌声与表演。**这是「≤3 段视频」额度最有价值的用法**。

### 5C. 剪辑节奏与音乐迁移

```
@图1@图2@图3@图4@图5@图6，严格参考@视频1的镜头节奏、转场风格及音乐
```

要点：用一批静态图 + 一条节奏参考视频，可以让 H3 直接产出成段剪辑。适合快速出 mood film / 概念片。

### 5D. 音色迁移与克隆

```
角色说话：Follow the wind, live free. Leave worries behind, enjoy the moment，音色参考@音频1
```

要点：音频必须配图片或视频一起传。音色参考解决的是**音色一致**，不解决吞字、读错品牌名、精确卡点——这三类仍须走后期录制。

## 6. 编辑模式的边界

1. **输入视频总时长 ≤ 15 秒**，输出仍是 4-15 秒。长片只能分段改，段与段之间的一致性靠**同一批参考素材 + 同一套锁定描述**维持。
2. **不能局部重抽**：编辑结果不满意只能整条重来，所以修改点尽量一次列全（手册验证过一条 6 处并列）。
3. **人脸替换风险最高**：换服装、换道具、换背景成功率远高于换脸。涉及主角身份变更时优先回生成模式。
4. **改完要重新过一遍声音**：H3 输出全部带声，编辑后的条目声音可能被重新生成——编辑指令里要把声音要求也写上（`保持原视频的环境声不变` 或重新点单）。
5. **编辑条也要做验收申报**：在提示词代码块外写明改了哪几处，供 `release-gate` 素材验收逐条核对：

```
✂️ 编辑申报：源素材 @视频1（原时长 X 秒）｜ 修改点 N 处：①…… ②…… ③……
   保留锁：透视/光影/景深/运镜/时序/遮挡 ｜ 声音处理：{保持原声 / 重新点单：……}
   验收：逐条核对修改点已生效 + 未被要求改的部分逐帧比对无漂移
```
