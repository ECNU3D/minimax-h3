## 1. 六段式骨架

H3 手册里效果最好的提示词，几乎都是这六段。顺序不要乱，缺哪段就在哪段翻车。

| 段 | 内容 | 缺失后果 |
|----|------|---------|
| ① 交付规格 | 时长 + 画幅 + 体裁。`生成一支 15 秒、9:16 竖屏海外真人吸血鬼爱情短剧预告片段` | 画幅飘、节奏对不上 |
| ② 素材职能声明 | 每个素材干什么用。`@图1 是整体质感、氛围参考，@图2 是人物外表特征参考` | H3 自己猜图的用途，多素材头号翻车原因 |
| ③ 一致性锁定 | 把必须锁死的外观逐项点名。`保持人物一致：白金色长发、窄黑色复古墨镜、黑色高光漆皮风衣、冷酷自信的时尚表情` | 跨条素材人物换脸换衣 |
| ④ 内容主体 | 单镜描述，或 Shot / 时间轴分段（见第 2、3 节） | — |
| ⑤ 声音设计 | 白名单钳声 或 完整 BGM 点单（见第 5 节） | H3 原生带声，不管就随机配乐，多条剪一起会打架 |
| ⑥ 负面清单 | `不要字幕、不要平台水印、不要现代服装、不要动画感、不要过度磨皮` | H3 自作主张加元素、往恐怖/喜剧方向跑 |

**③ 一致性锁定的写法要点**：只写「与参考图一致」是不够的，要**逐个部件点名**。手册的正例：

```
使用@图2作为固定人物参考，保持黑色半扎长发、银色镂空发冠、黛蓝发带、浅色层叠汉服、
半透明蓝色外袍、深蓝腰封、银色花形扣饰和长流苏一致。
```

## 2. 单镜模式模板

一条 = 一个连续镜头，4-8 秒。适合需要逐镜精修、逐镜验收、跨镜首尾帧锚定的叙事片。

```
[① 时长 + 画幅 + 体裁]。[② 素材职能声明]。
[③ 一致性锁定：逐部件点名]。
[④ 运镜] + [主体外观与状态] + [场景/光线/氛围] + [动作序列，必要时用 0-3秒/3-6秒 分段] + [情绪与表情变化]。
[⑤ 声音：白名单或点单]。
[⑥ 负面清单]。
```

**极简也成立**——H3 对短提示词的执行力很好，简单动作不要过度堆砌：

```
固定镜头，机器臂下降，抓起红色方块，向前移动一段距离后放下
```

## 3. 序列模式模板

一条 = 一个 10-15 秒的完整多镜段落，含硬切与转场。适合片头包装、TVC、预告片、UI/UX 演示、产品卖点片。手册里有两种写法，都验证过。

### 3A. 时间轴式（适合 UI 演示、产品流程、卖点罗列）

```
[① 时长 + 画幅 + 体裁]。[② 素材职能声明]。

[0秒-2秒] [景别与机位]。[画面内容]。[UI/文字事件]。
[2秒-4秒] [镜头变化]。[画面内容]。
[4秒-7秒] [镜头变化]。[画面内容]。
[7秒-8.5秒] [镜头变化]。[画面内容]。
[8.5秒-10秒] [画面内容]。
[10秒-15秒] [收尾画面 / 环境加载 / 品牌落版]。

[⑤ 声音]。[⑥ 负面清单]。
```

### 3B. Shot 式（适合电影预告、片头、氛围向）

```
[① 时长 + 画幅 + 体裁]。[② 素材职能声明]。写实电影感，高反差光影，节奏紧凑。

Shot 1 — [景别与功能，如「超广角建立镜头」]。[画面内容]。[文字包装事件]。
Audio: [该镜声音事件]。
→ Hard cut.

Shot 2 — [景别与功能]。[画面内容]。
Audio: [该镜声音事件]。
→ Hard cut.

[⑥ 负面清单]。
```

### 序列模式的转场词库

手册案例里跑通过的转场写法：

> 圆形黑胶遮罩 · 车门竖切 · 人物长影擦屏 · 红线切割 · 巨大英文字母遮罩 · 分屏边框重组 · 色块硬切 · 画格逐块贴入 · 望远镜扫视转场（甩动 + 运动模糊 + 光学拖影 + 曝光闪烁，在最模糊处切换并迅速稳定重新对焦） · 快速硬切 · 强光爆闪 · 短黑场 · 闪白转场

**节奏绑定**：写 `所有转场跟随鼓点，干脆、悬疑、灵动`，比写「节奏快」有效得多。
**反向约束**：不想要柔和过渡就写死 `不要柔和溶解，不要流体转场`。

### 序列模式的代价（决定用不用之前先看）

- 单条内的某一个镜头**不能单独重抽**，任何一处翻车都是整段重来。
- 与逐镜验收流程（`release-gate` 素材验收）冲突——序列条要按「整段」验收，验收清单要写成段内逐镜检查项。
- 7000 字符上限在序列模式下容易逼近，写完数一下。

### 两条实用的画面控制规则（手册原文）

**远景不给正脸**（对付 AI 远景人脸崩坏）：

```
人物露脸只能是近景或特写，远景只能是背影、侧背或环境空镜，不要正脸远景。
```

**分镜之间不许像 PPT**：

```
镜头依次表现分镜中的内容，确保每个分镜之间运镜、切换自然，不能像ppt一样。
```

## 5. 声音设计写法

**H3 所有输出都带声音（原生双声道）**，声音必须主动管，否则随机配乐。

### 5A. 白名单钳声（默认做法）

用「声音只使用……」句式，把允许出现的声音穷举，其余自然被排除：

```
声音只使用厨房室内环境声、抹布摩擦声、马克杯轻微碰撞声、水龙头水滴声、
拍摄者的脚步声与轻微呼吸声，以及手绘生物柔和的电子音和小小的叫声。
```

若全片音乐走后期统一设计，白名单里**不要放音乐**，并补 `不要背景音乐`。

### 5B. 完整 BGM 点单（需要模型出配乐时）

手册里最完整的一条 BGM 描述，五个要素齐全——风格配比 / 乐器清单 / 分段编曲进程 / 情绪定调 / 禁令：

```
BGM：原创15秒片头音乐，60%悬疑、40%爵士。以低音持续音、紧张弦乐拨奏、冷感合成器脉冲、
低音鼓、稀疏爵士鼓刷、walking bass 片段、低音萨克斯短句和短促铜管点缀组成。
前2秒神秘低频和踩镲建立悬疑，第3秒进入低沉鼓点，第6秒加入爵士贝斯律动，
第10秒出现短促萨克斯/铜管riff，最后2秒用紧张和弦加鼓点定格。
整体神秘、酷、带犯罪感，爵士只占40%，不要太欢快，不模仿任何现有旋律。
```

`不模仿任何现有旋律` 这一句在商业投放场景务必保留。

### 5C. 逐镜声音事件（序列模式）

Shot 式写法里每个 Shot 挂一行 `Audio:`：

```
Audio: 深低频脉冲，远处金属轻震，文字清晰时一记轻 hit。
```

### 5D. 音色克隆

音频必须配图片或视频一起传，不能单独传音频：

```
角色说话：Follow the wind, live free. Leave worries behind, enjoy the moment，音色参考@音频1
```

## 7. 负面清单词库

H3 会自作主张加元素、往恐怖或喜剧方向跑。按体裁取用：

| 体裁 | 负面清单 |
|------|---------|
| 通用画面 | `不要字幕、不要文字、不要水印、不要平台水印、不要贴片` |
| 写实短剧 | `不要现代服装、不要现代建筑、不要动画感、不要过度磨皮、不要明亮白天、不要喜剧表演、不要夸张舞台腔` |
| 悬疑/轻恐怖 | `禁止出现巨大的眼睛、裂开的嘴、獠牙、威吓、扑袭动作、突然黑屏和跳吓` |
| 海外短剧 | `不要血腥，不要廉价恐怖，不要万圣节感，不要现代街头感` |
| 参考图保真 | `严禁新增人物车辆建筑logo，保持原图核心构图与XX装置不变` |
| 转场 | `不要柔和溶解，不要流体转场` |
| 文字动效 | `禁旋转弹跳或大幅飞入飞出` |
| 音乐 | `不模仿任何现有旋律`、`不要背景音乐` |

## 8. 真实案例精选

### 多素材职能分工（时尚 campaign）

```
制作一支 16:9 横版高级时尚品牌视频。整体氛围、场景和胶片质感参考@图1；包袋资产参考@图3；
人物资产参考@图2；品牌 ending logo 参考@图4。这是一支卖衣服和包的时尚 campaign，整体气质要
高级、冷感、克制，但剪辑不能无聊，要更灵动、更有时尚节奏。不要像普通剧情片，也不要像电商广告。
核心故事依然很简单：荒漠公路和复古车旁，女人回到车尾，打开后备箱，取出黑色包袋，和站在车边的
男人有一瞬间的安静关系，然后她拿着包离开。包和服装要自然融入人物行动里，成为角色气质的一部分。
```

### 材质同构转场（一镜到底，微观→宏观）

```
@图1 镜头先快速推进到咖啡表面的奶泡、可可粉颗粒和深色咖啡液体纹理细节，让咖啡表面的颗粒、
泡沫和液体涟漪逐渐覆盖全屏，遮挡住其他东西。镜头保持真实微距质感，极浅景深，细小粉末在逆光中
缓慢飘落，表面纹理像细沙与流体之间的过渡。避免画面开裂，在咖啡粉颗粒、奶泡起伏、液体旋涡与
@图2 中沙丘沙脊、风蚀纹理、扬沙颗粒高度相似的瞬间，自然无痕转化为沙漠地貌，然后镜头继续向前
推进，展示出@图2 的沙丘全貌。严格避免画面开裂，不要黑屏，不要硬切，不要明显特效，不要拼接感，
整体真实、安静、克制，像同一种颗粒材质从咖啡微观表面自然变成宏观沙漠世界。一镜到底，中间不要出现拼接。
```

要点：**同构转场要点名两侧的共同物理特征**（颗粒 / 纹理 / 起伏），并反复写死「不要拼接感」。

### 关键帧串联 + 固定遮罩（望远镜窥视）

```
@图1至@图4连续关键帧，模拟老式望远镜寻装置。开头虚焦手持晃动后快速拉近 rack focus 至@图1，
图间望远镜扫视转场（甩动、运动模糊、光学拖影、曝光闪烁）在最模糊处切换并迅速稳定重新对焦。
全程固定双圆镜片遮罩（黑色羽化暗角、位置大小边缘虚化绝对一致无变形漂移）仅内部画面运动。
```

要点：**遮罩类元素必须写「位置大小边缘虚化绝对一致无变形漂移」**，否则每帧都会漂。

### 竖屏短剧对峙（表演指导写法）

```
室内家庭争吵短剧场景，竖屏短剧质感，真实真人表演，中式家庭/小饭馆室内环境，暖色灯光，
背景有红色装饰和书法字幅，浅景深，情绪强烈，剪辑节奏紧凑。
表演要求：真实短剧表演风格，不要夸张舞台腔。A 的语气是愤怒、委屈、急切的反驳；
B 的语气是尖锐、强势、咄咄逼人的质问。两人之间有强烈对峙感，节奏逐步升级。
画面风格：竖屏9:16，手机短剧质感，真人实拍感，浅景深，室内暖光，中近景为主，频繁正反打剪辑，
背景保持生活化，不要科幻、不要古装、不要动画感。画面中不要出现任何字幕、文字、平台水印或贴片。
```

要点：**「表演要求」单列一段，逐角色写语气与关系张力**，比在动作描述里夹带形容词有效。

### 实拍 + 手绘动画混合

```
15秒、16:9横向视频。将傍晚小厨房的真人实拍与手绘发光动画融合在一起的影像。夕阳余晖还残留在
窗边，生活感十足的小厨房里有一张旧木桌、洗到一半的马克杯、略微起雾的玻璃瓶，以及悬挂着的抹布。
画面带有像用智能手机单手拍摄一样的细微手抖、近距离对焦时的犹豫、逆光造成的曝光波动，以及
暗部略显粗糙的噪点。不要像广告影像那样精心整理，而是要呈现出像是在家中慌忙拍下某个不可思议
事件的自然质感。禁止出现巨大的眼睛、裂开的嘴、獠牙、威吓、扑袭动作、突然黑屏和跳吓。
声音只使用厨房室内环境声、抹布摩擦声、马克杯轻微碰撞声、水龙头水滴声、拍摄者的脚步声与
轻微呼吸声，以及手绘生物柔和的电子音和小小的叫声。
```

要点：这条把 ①④⑤⑥ 四段写全了，是纯文生条的标准长度参照。

### 产品功能可视化（电商卖点片）

### 游戏 UI 演示（时间轴式序列，完整参照）

```
角色参考@图1，UI风格参考@图2。
[0秒-2秒] 高角度俯拍。角色坐在高饱和度的亮紫色地面上，抬头看向摄像机。右侧显示游戏菜单 UI：
开始新游戏 (START NEW GAME)、继续游戏 (CONTINUE, 高亮显示)、设置 (SETTINGS)、退出游戏 (EXIT GAME)。
左上角显示玩家资料 MINIMAX。光标点击"继续游戏"。
[2秒-4秒] 平滑变焦至她的右臂。UI 面板从右侧滑入，"右臂装备 (RIGHT ARM EQUIPMENT)" 面板出现。
选中高亮显示 "幻影之握 (PHANTOM GRIP)"，随后滑动至 "时空之爪 (CHRONOS CLAW)"。她的右手机械地
重新配置，手指分开，新的爪状指节锁定到位，青色 LED 灯闪烁得更亮。
[4秒-7秒] 摄像机平滑地绕到她的左侧。新的 UI 滑入 "武器定制 (ARMAMENT CUSTOMIZATION)" 网格……
[7秒-8.5秒] 摄像机拉回至中景。确认配置 (CONFIRM CONFIG) 按钮闪烁。点击。所有 UI 面板向内收缩消失。
[8.5秒-10秒] 底部出现加载 (LOADING) 条。从 0% 快速填充至 100%。
[10秒-15秒] 当她起身时，完整的环境在她周围加载。密集的赛博朋克贫民窟显现……HUD 元素淡入，
右上角显示小地图，左下角显示生命值和弹药计数器。任务标记出现。她迈步走进街道。
```
