# 画面内文字与字幕控制（H3）

> H3 把「文字字幕、品牌信息」列为核心能力之一，手册案例里模型直接画出了片头标题、英文署名、UI 菜单、中文落版字。
> **本技能允许模型画字（含中文）**，但必须按下面的规范点单，并把验收项交给 `release-gate`。
> 这与同族的 seedance / vidu / hailuo / wanxiang 技能「一律后期卡字」的惯例不同——**只在 H3 上放开**。

## 1. 文字点单的五要素

只写「出现标题 XXX」必然随机。手册中成功的案例都写全了这五项：

| 要素 | 写法示例（手册原文） |
|------|-------------------|
| **内容**（逐字写死） | `"THE STARS WERE LISTENING"`、`结尾"灵感与舒适同时在线"字样浮现` |
| **字体形态** | `字体极窄、厚重、全大写`、`电影预告片式宽字距标题包装`、`粗犷有力、倾斜的超大号无衬线字体` |
| **颜色与材质** | `暗红混合铁锈红，带轻微颗粒和雾化边缘`、`字体不要纯白，要有克制发光和材质感、微弱边缘辉光` |
| **入场/出场动效** | `从黑暗边缘渐入，先模糊后清晰`、`初现略虚焦低透明度0.3–0.5秒内淡入变清晰`、`切换前淡出或被运动模糊带走` |
| **停留与可读性** | `最后短暂停住`、`MINIMAX文字随布面起伏保持可读`、`英文署名要清晰可读` |

**完整点单示例（拼合手册两条案例的写法）：**

```
大标题从黑暗边缘渐入，先模糊后清晰："THE STARS WERE LISTENING"，字体极窄、厚重、全大写，
暗红混合铁锈红，带轻微颗粒和雾化边缘，字距缓慢展开，清晰后短暂停住 1 秒，随后被黑场闪现带走。
```

**文字与画面绑定**：文字贴在运动物体上时，要写清它怎么跟随——`@图2 布料随风克制飘动，MINIMAX 文字随布面起伏保持可读`。

**文字音效**：H3 原生带声，文字出场可以点音效——`文字出来时配上灵动文字出场的音效`。

## 2. 动效词库与禁令

### 可用动效（手册验证过）

淡入 / 淡出 · 先模糊后清晰 · 从深空暗部渐入 · 被星光扫亮 · 字距展开 · 字距呼吸 · 微小纵向滑入 · 字母逐个出现 · 细线框先画出后名字从框内滑入 · 被色块遮罩揭示 · 残影 · 微弱发光 · 黑场闪现 · 随对焦轻微加载 · 被运动模糊带走

### 必写禁令

```
禁旋转弹跳或大幅飞入飞出。
不要乱码，不要错拼。
```

高级质感片子里，文字动效越克制越贵。手册的时尚/预告案例全部只用淡入、字距、遮罩、发光这几类。

## 3. 全片级文字规则

序列模式里一条提示词包含多屏文字（片头署名、UI 菜单、卖点字幕）时，模型会重复和错配。手册给了明确的全片级约束写法：

```
全片规则：所有英文署名和职位只出现一次。不要重复同一个职位，不要重复同一个人名，
不要让同一个人担任多个职位。
```

推广到其他场景：

- **署名/职位表**：逐条列出，写死「只出现一次」。
- **UI 文案**：中英双写 `继续游戏 (CONTINUE, 高亮显示)`，让模型两边都能对上。
- **卖点字幕**：每屏字幕绑定到具体时间段，不要让模型自由分配。
- **落版字**：写清是「浮现」还是「打字机」还是「硬切」，并给停留秒数。

## 4. 中文字的能力边界与降级预案

**有案例支撑的中文字**（可以交给模型）：

- 短落版字 / Slogan：`结尾"灵感与舒适同时在线"字样浮现`（8 字）
- UI 菜单项：`开始新游戏 (START NEW GAME)`（中英双写）
- 招牌/包装上的少字替换：`"全家"便利店招牌修改为"互惠"招牌`（2 字）

**无案例支撑、风险高的**：

- 长句中文字幕（>12 字）、整段对白字幕
- 手写体/书法体中文
- 密集中文排版（多行小字、正文段落）
- 一屏内出现 3 组以上不同中文字串

手册自己的悬疑片头案例里写的是 `不要新增中文，不要乱码，不要让英文错拼`——**说明中文错字是已知风险，模型团队自己也在规避**。

### 降级预案（按顺序尝试）

1. **缩短**：把长中文压到 8 字以内。
2. **拆屏**：一屏一句，分配到不同时间段，别挤在一起。
3. **中英双写**：中文旁挂英文，模型有两套字形可对。
4. **转后期**：仍不稳定就退回后期卡字——从提示词正文里删掉文字内容，正文改写 `画面下三分之一留出干净区域，不要出现任何文字`，文字进后期卡字清单。

> ⚠️ **品牌名 / 产品名 / 法务必现文案（如「广告」标识、免责声明）建议直接走后期。**
> 不是因为 H3 画不出，而是因为**一个字错就整条素材作废且不可局部修**，而这类文案的容错率是零。
> 若客户坚持要模型画品牌字，必须在脚本里写明「该条需逐帧核字，错字即重抽」，并预留重抽预算。

## 5. 文字验收清单（交给 release-gate）

每条含画面内文字的镜，在提示词代码块**外**补一行申报，供 `release-gate` 成片体检直接取用：

```
🔤 画面内文字：{逐字抄写的文字内容} ｜ 语种：中/英 ｜ 出现区间：{X-Y秒} ｜ 责任方：🅜模型绘制 / 🅟后期卡字
   验收项：①逐字比对无错字漏字 ②无乱码/异形字 ③全程可读（不被运动模糊/遮挡吞掉）④未重复出现 ⑤安全区内未被平台 UI 遮挡
```

**验收执行要点：**

1. **逐字比对**：暂停在文字最清晰的一帧，把画面里的字一个一个抄下来，和脚本原文比对。不要凭印象扫一眼。
2. **全程可读**：文字在入场、停留、出场三个阶段都要检查，模型常在入场阶段把字画歪、出场阶段提前糊掉。
3. **重复检查**：序列条里搜同一人名/职位是否出现两次。
4. **安全区**：竖屏 9:16 投放时，顶部约 15% 和底部约 20% 会被平台 UI 压住，文字不要落在这两条带里。
5. **一票否决**：错字、乱码、重复署名 = 该条素材不通过，重抽或转后期，**不允许「凑合能看」放行**。
