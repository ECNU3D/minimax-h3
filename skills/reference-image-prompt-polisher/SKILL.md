# Reference Image Prompt Polisher

用于把粗糙描述或已有提示词整理成更稳定、更清晰、更适合图像模型理解的中文提示词。

核心产出是**提示词**，重点是保证角色一致性、场景连续性和整体风格统一。

提示词写完**不是终点**：按文末「从提示词到图片」一节交给 `gpt-image-bridge` 生成并逐张验收，再进入视频生成。

## 支持的输入

- 已有的人物、场景、首帧或尾帧粗提示词
- 单镜头描述、多个镜头、整段分镜或剧情段落
- 用户指定的风格词、媒介感、色彩倾向或参考关系
- 用户要求的输出约束，例如“只要提示词”“严格简洁”“保留原风格”

## 工作模式

根据用户输入先识别为以下模式之一：

- 润色已有提示词
- 只生成人物参考图提示词
- 只生成场景参考图提示词
- 只生成首帧提示词
- 生成首尾帧提示词
- 分镜拆解并生成完整参考图提示词
- 混合模式

## 核心流程

### 1. 识别任务目标

先判断用户究竟要：

- 润色现有提示词
- 从分镜里拆资产
- 只产出某一类参考图
- 输出解释加结果，还是只输出结果

### 2. 提取全局风格

- 用户明确指定风格时，直接保留并统一
- 用户只说“统一风格”时，从 [styles.json](references/styles.json) 里选择最匹配的预设
- 用户风格模糊时，基于题材推断一个最合适的预设，并在输出里写明推断结果

统一风格时至少覆盖这些维度：

- 媒介感
- 色彩倾向
- 光线逻辑
- 纹理与质感
- 构图倾向
- 连续性规则

### 3. 区分稳定元素和镜头特有元素

人物稳定元素：

- 年龄段
- 脸型
- 发型和发色
- 身形
- 服装逻辑
- 标志性配饰或道具
- 气质

人物镜头特有元素：

- 姿势
- 表情
- 动作
- 机位
- 当前光线状态

场景稳定元素：

- 地点类型
- 室内或室外
- 建筑或地形特征
- 季节、天气、时间段
- 核心空间结构
- 核心陈设
- 气氛与色调

场景镜头特有元素：

- 当前镜头角度
- 当前景别
- 当前人物位置
- 临时动作元素
- 当前局部光效

### 4. 决定输出哪些资产

默认遵守以下规则：

- 同一个重复人物只生成一次人物参考图提示词
- 同一个重复场景只生成一次场景参考图提示词
- 同一人物若服装形态完全不同，可拆成多个版本
- 同一场景若昼夜、季节或完整度差异极大，可拆成多个版本
- 首帧按镜头生成
- 尾帧只在必要时生成

人物参考图生成条件：

- 出现命名角色
- 存在反复出现的主要人物
- 同一角色跨多个镜头出现
- 用户明确要求人物参考图、三视图、角色设定图或定妆图

场景参考图生成条件：

- 同一地点在多个镜头中重复出现
- 场景本身很重要，需要统一空间结构和气氛
- 用户明确要求场景参考图

首帧生成条件：

- 用户希望为视频生成准备参考图
- 用户给了镜头或分镜
- 用户明确提到首帧
- 某个镜头的起始状态很重要

尾帧生成条件：

- 用户明确要求首尾帧模式
- 用户明确说需要尾帧
- 镜头结束状态对视频生成很重要
- 镜头设计为从 A 过渡到 B

如果用户只是要单张参考图，不要强行输出尾帧。

### 5. 生成提示词

所有提示词尽量按这个顺序组织：

1. 图片用途
2. 主体
3. 场景
4. 当前状态或动作
5. 构图与机位
6. 光线与氛围
7. 风格
8. 一致性约束
9. 画面清洁约束

## 资产级规则

### 人物参考图

目标：

- 稳定人物身份
- 明确造型
- 为后续视频生成提供一致性基准

默认规则：

- 默认全身
- 默认干净背景
- 默认中性站姿
- 默认光线均匀
- 默认无文字无水印
- 默认突出轮廓和服装层次
- 默认优先生成一张正面全身的主参考图，再基于这张图生成三视图整合图
- 默认不要把不同视角拆成多套独立提示词或多张独立图片，除非用户明确要求按视角分别出图

人物参考图默认分两步思考：

1. 先生成主参考图提示词
2. 再生成三视图整合图提示词

主参考图提示词用于先生成一张单人、正面、全身、纯净背景的人物锚点图。这个阶段的重点是把脸、发型、服装、体型和标志性道具固定下来。

三视图整合图提示词用于在已经有主参考图的前提下，基于该图作为人物参考，再生成一张包含多个视角的角色设定图。默认是一张图内包含正面、侧面、背面；如果用户明确需要，也可以改成正面、四分之三侧、侧面、背面，但仍然是一张图，不是多张独立图。

如果用户明确提到三视图，默认输出：

- 一条主参考图提示词
- 一条三视图整合图提示词

如果用户提到人物参考图、角色设定图或定妆图，但没明确视图数量，默认输出：

- 只要单角色锚点时，输出一条主参考图提示词
- 如果上下文明显是在为视频一致性或设定图做准备，再补一条三视图整合图提示词

三视图整合图提示词里要明确这些约束：

- 基于已生成的正面全身主参考图作为唯一人物参考
- 同一张图中展示多个视角
- 保持同一人物身份、脸型、发型、服装和配色一致
- 不要生成多个人物，不要让不同视角看起来像不同角色
- 背景保持简洁，重点服务角色结构展示

### 场景参考图

目标：

- 固定环境气质
- 固定空间结构
- 固定时间、天气和色调
- 为后续视频保持环境连续性

默认规则：

- 没必要时不要放人物
- 强调前景、中景、背景层次
- 强调空间可读性
- 强调时间、天气和光线逻辑
- 默认优先生成一张场景主视图参考图，再基于这张图生成四个方向的四宫格整合图
- 默认不要把四个方向拆成四套独立提示词或四张独立图片，除非用户明确要求逐方向分别出图

场景参考图默认分两步思考：

1. 先生成场景主视图提示词
2. 再生成场景四宫格整合图提示词

场景主视图提示词用于先生成一张最能代表该环境的主锚点图。这个阶段的重点是把地点类型、空间结构、时间天气、主要材质、光线逻辑和整体气氛固定下来。

场景四宫格整合图提示词用于在已经有场景主视图的前提下，基于该图作为环境参考，再生成一张包含四个方向的环境设定图。默认是一张图内展示同一地点的四个方向视角，用于补足空间结构和方向关系，而不是生成四张彼此独立的图。

如果用户明确提到场景四宫格、四个方向、环境设定图、空间方向图，默认输出：

- 一条场景主视图提示词
- 一条场景四宫格整合图提示词

如果用户提到场景参考图，但没明确说要四个方向，默认输出：

- 先输出一条场景主视图提示词
- 如果上下文明显是在为视频连续性、环境搭建或空间统一做准备，再补一条场景四宫格整合图提示词

场景四宫格整合图提示词里要明确这些约束：

- 基于已生成的场景主视图作为唯一环境参考
- 同一张图中展示同一地点的四个方向
- 保持同一地点的建筑结构、地形关系、材质、时间、天气、光线和色调一致
- 四个方向之间要能互相印证空间关系，不要变成四个不同地点
- 背景与陈设可以因视角变化而不同，但核心空间骨架必须稳定
- 如果场景里允许出现人物，人物只能作为比例参照，不得喧宾夺主

### 首帧

目标：

- 定义镜头开始时的画面状态
- 明确主体位置、动作起点、场景结构和镜头语言
- 让后续视频生成更容易起步

### 尾帧

目标：

- 明确镜头结束时的画面状态
- 与首帧形成自然过渡关系
- 保持人物、场景和风格连续

## 输出规则

### 统一写法原则

- 优先写清楚，不堆砌空泛形容词
- 优先保证主体、轮廓、背景和空间关系可读
- 分层表达主体、环境、状态、构图、风格和约束
- 润色时保留原意，不擅自改变人物身份、年龄感、服装核心设定、发型、核心道具、场景类型和关键叙事动作
- 如果用户同时给了角色参考、环境参考和风格参考，明确各自作用

> ⚠️ **硬规则：每条提示词正文必须「自包含」——严禁跨镜/跨图引用。**
> 文生图与视频生成一样，**每次生成都是独立的、没有上下文**，模型看不到"镜16""镜01 尾帧""全身设定图""红版"。所以在可粘贴的提示词正文里写这些一律无效，且是**锚定没到位**的信号：
> - ❌ `【用途：……供镜X 一致性】` 这类前缀、`一致性约束：与镜X 同机位 / 与镜Y 完全一致 / 与全身设定图同一人物 / 与@图6-主一致 / 与红版布局一致 / 与镜20 一致`
> - ❌ `维持XX / 沿用XX / 复现XX / 同机位 / 首帧承接镜X`
>
> 要一致，只能靠两种真正有效的手段：
> 1. **详细的自包含描述**——把要锁定的五官/配色/构图/道具花纹在本条提示词里从头写全（如面部图不写"与全身图同一人物"，而把发型、脸型、衣领配色、神情逐一描述）。
> 2. **挂参考图 `@图X`**——生成本图时把要对齐的那张图作为参考图一并上传（如生成面部锚点时挂全身设定图；生成青蓝版俯拍时挂红版俯拍图）。
>
> 用途说明、"供哪些镜头使用""与哪张图同机位"这类**给人看的元信息，一律写在代码块外**，不进可粘贴的提示词正文。
> 首尾帧成对提示词也各自独立成篇：不写"同镜X 首帧机位"，而是把机位/构图/四地标方位在每条里各自描述清楚，靠共享 `@图X` 保证成对一致。
> 自检：每条提示词单独拎出来读，脱离全文也能生成、不含任何"镜编号/维持/一致/同机位/供X"。

> ⚠️ **硬规则：方位一律写「画面方位」，不写「人物方位」。**
> 写「铁钎在**他身体的右前方**，左前方是空的」会被理解反——人物面对镜头时，模型要先做一次镜像换算（人物的右＝画面的左），这一步经常出错。
> - ❌ `他的右手边放着水壶，左手边是空的`
> - ✅ `水壶在画面的左半边，画面右半边完全空着`
>
> 方位正反双写仍然要做（写清「在哪边」也写清「另一边是空的」），但**两端都用画面方位**。人物视角的方位只写在代码块外的说明行里给人看。

### 默认负面约束

如果用户没有要求单独输出 negative prompt，在提示词末尾用一句简洁约束概括即可，例如：

- 无文字
- 无水印
- 无多余人物
- 无畸形肢体
- 无模糊面部
- 无杂乱背景
- 无重复主体

只有在用户明确要求时，才单独输出 `negative prompt` 字段。

> ⚠️ **硬规则：服装写结构，不写品类词——品类词会自动带出制式细节。**
> 写「军绿色**双排扣**大衣」，模型会自动补一排铜扣、立领、军装剪裁，出来接近制式军大衣；在酒类、医药、金融等受管制品类的广告里，这会直接踩「不得变相使用军旗军徽」「不得使用国家机关工作人员形象」之类的红线。
> - ❌ `军绿色双排扣大衣`
> - ✅ `深藏青色厚棉大衣，金属拉链从下巴拉到腰部，拉链外盖一层同色门襟布，没有铜扣、没有双排扣、没有肩章臂章、没有任何徽章`，并补一句 `不是军装、不是制服、不是任何执法或公务人员着装`
>
> 同类雷区：军装、警服、白大褂、法官袍、校服。凡可能被读成「制服」的服装，都要在提示词里显式否定一次。

### 默认保存规则

默认保存约定：

- 保存格式：`.md`
- 保存位置：当前工作目录
- 默认文件名：`{主题关键词}-参考图提示词.md`

- 场景参考图提示词

- 尾帧提示词

如果某一类内容本次没有生成，就不要在文件里保留空章节。

## 从提示词到图片

本技能的产物是提示词，不是图片。提示词写完之后**不要停在这里**——直接调用 `gpt-image-bridge` 技能把它们生成出来，并逐张验收。

### 两级锚定

一致性不是靠提示词写得多细堆出来的，是靠**参考图锚定**。分两级：

**第一级：设定图（人物 / 场景 / 元素锚定图）**
- **不挂参考图**，纯文字生成——它们本身就是基准，挂参考图会自我循环
- 每条抽 3–4 张备选
- 逐张过验收清单，不过就重抽，**不要将就**：设定图是后面所有图的地基，这里让一步，后面每一张都要还

**第二级：首帧图 / 分镜图**
- **必须挂对应的设定图作参考图**：有人物的镜挂角色设定图，环境镜挂场景设定图，特殊元素镜挂元素锚定图
- 不挂的后果是确定的——同一个角色在不同镜头会长出不同的脸，事后无法修，只能重生成
- 逐张验收，重点查跨图一致性（同一角色的脸与服装、同一元素的色温与形态）

**第三级：交给平台分镜技能**（seedance / h3 / hailuo / vidu / wanxiang），进入视频生成。

### 调用方式

```bash
# 第一级：设定图，不挂参考图
~/.claude/skills/gpt-image-bridge/bin/gpt-image-2 \
  "<角色设定图提示词全文>" \
  "<项目>/参考图/角色A-XXX.png" --size 1024x1536

# 第二级：首帧图，挂设定图当身份锚
~/.claude/skills/gpt-image-bridge/bin/gpt-image-2 \
  "<首帧提示词全文>" \
  "<项目>/参考图/首帧/S05.png" \
  --ref "<项目>/参考图/角色A-XXX.png" \
  --ref "<项目>/参考图/场景3-XXX.png" \
  --size 1024x1536
```

### 参考图锁得住什么、锁不住什么

| | |
|---|---|
| **锁得住** | 长相、发型、服装每一件、配色体系、画风 |
| **锁不住** | 构图、姿态、镜头角度、光线方向 |

挂了参考图**不等于**可以省略文字描述——姿态和构图仍然要在提示词里写清楚。
