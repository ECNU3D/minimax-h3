# 分镜审片系统

## 概述

对已完成的分镜脚本进行专业级质量审查，从9个维度评分并输出结构化审片报告和优先级修改清单。本技能是分镜创作流程的质量关卡，审查对象为 seedance/hailuo/wanxiang/vidu 等分镜技能的输出产物。

审查回答两个不同的问题，缺一不可：①这片子拍得专业吗（工艺维度 1-8）；②**一个零背景观众第一遍能看懂吗（维度 9，权重最高）**。历史教训：曾有脚本工艺拿到 B+/A、"可放心生成"，成片却被观众普遍反馈"讲不清楚故事"——因为旧尺子 94% 权重在工艺，没人替观众坐在黑暗里。

## 触发条件

- 用户已有完成的分镜 Markdown 文件，希望进行质量审查
- 用户提到"审查"、"审片"、"分镜审查"、"质量检查"、"review"

## 输入

1. **必须**: 已完成的分镜 Markdown 文件（seedance/hailuo/wanxiang/vidu 分镜技能的输出）
2. **可选**: 视觉设计文档（VDD），用于色彩连续性审查

## 参考资料

审查前必须加载以下参考文件：

- `references/review-checklist.md` — 维度1-8详细审查标准
- `references/shot-audit-rules.md` — 景别/运镜识别规则与扣分规则
- `references/comprehension-audit.md` — 维度9（信息传达与可懂性）审查协议：盲审复述、静音/黑屏测试、五项硬性检查与扣分规则
- `../narrative-info-planner/references/beat-rhythm-rules.md` — 拍点尺（维度5叙事节奏子项的唯一标准源：拍点定义、空窗、配比、体量系数）
- `../narrative-info-planner/references/explainer-formula.md` — 解说漫剧配方（审解说体裁时，维度5A/9 对照其六步法与验收标准：钩子位置、计数框架单一性、先白话后引文、K卡清单在场）

## 工作流程

### 第一步：解析分镜文件

逐条提取每个镜头的元数据：

| 字段 | 说明 |
|------|------|
| 分镜编号 | Shot #1, #2, ... |
| 时长 | 秒数 |
| 场景 | 所在场景名称 |
| 运镜方式 | 从提示词开头提取 |
| 景别 | 从提示词中识别 |
| 提示词全文 | 完整 prompt 文本 |
| 风格尾缀 | 提示词末尾的风格/画质描述 |

如果用户同时提供了 VDD，也解析 VDD 中的色彩地图、角色色彩身份、色彩叙事弧线。

### 第一步半：声画分轨机械扫描（前置硬伤，先扫再评分）

进入维度分析之前，先跑三条**机械检查**——这类错误可以被 grep 出来，不该靠"读起来还行"放过。判定标准见 `narrative-info-planner/references/audio-lane-rules.md`。

1. **块内人声扫描**：把每个提示词代码块单独拎出来，搜 `"` `“` `「` 和 `旁白｜广播｜画外音｜配音｜独白｜后录`。命中的每一处，判定它是 🅐（画面内开口、有口型、非品牌必听信息）还是 🅑（应后期录制）。**🅑 类出现在代码块内 = P0 硬伤**——模型会照写生成一条随机音色配音，与后期录音撞轨。
2. **双轨冲突扫描**：同一句台词是否既在代码块内、又在代码块外的「声音／后期」行或装配规范里？出现两次 = P0 硬伤（典型症状：正文写着广播台词，下面一行写着"广播必须后录"）。
3. **台词时长预算**：每句台词按 `可容纳字数 ≈ (窗口秒数 − 0.4) × 语速`（快对白 5／正常对白 4.5／广告旁白 4／失真广播·强调句 3–3.5 字每秒，破折号省略号每处扣 0.3 秒、逗号扣 0.15 秒）核算。**超窗 = P0 硬伤**（模型只会加速吞字或截断）。同一把尺子也用来验声音时间轴：每一行的窗口必须 ≥ 该句预算秒数。

扫描结果写进报告独立小节「声画分轨扫描」，逐条列出：镜号 · 台词全文 · 应属 🅐/🅑 · 实际写在哪 · 字数与预算 · 窗口 · 判定。扣分并入维度 7，规则见 `references/shot-audit-rules.md`。

> 历史教训（《请不要把童年吵醒》，2026-07）：镜 1 提示词正文写了 `画外失真童声广播"请不要在戏院食用——小小酥"`，同一镜「声音／后期」栏写着"广播必须后录"，而这句 11 字台词被塞进一个 1 秒窗口。三个错分属上面三条扫描，全部可机械检出，却在 A 级审片报告里整条漏过——因为九个维度没有一个在看"这句话由谁发声、装不装得下"。

### 第二步：9维度分析

按照 `references/review-checklist.md` 中的标准，逐维度分析：

1. **景别分布** — 统计各景别出现次数与占比，对照理想分布
2. **运镜多样性** — 统计运镜类型分布，检查叙事匹配度
3. **色彩连续性** — 对照 VDD 检查色彩一致性（无 VDD 时检查风格尾缀同质化）
4. **构图意图** — 检查每个镜头是否有空间安排指导（前景/中景/背景、人物位置、光影方向）
5. **节奏分析** — 分两个子项，**叙事节奏为主（占本维度 2/3）、剪辑节奏为辅（占 1/3）**。叙事节奏：按 `beat-rhythm-rules.md` 逐镜标注拍点类型（有 📌信息增量申报直接复用，无则自行判定），核算独立拍点平均间隔、最大空窗、前 60 秒钩子、主转折位置、放大+呼吸配比与挂靠、体量（N×类型系数 vs 实际时长）。剪辑节奏：时长分布变化性、高潮段是否加速。**历史教训：《好》剪辑节奏健康但两处 60 秒空窗+主转折 67%+配比超四成，旧尺子全程绿灯，成片被反馈"节奏太慢、内容太简单"——剪辑节奏满分买不回叙事节奏**
6. **视觉连续性** — 检查同场景光线一致性、角色外观一致性、时间连贯性
7. **提示词质量** — 检查风格尾缀同质化、光线描述、纵深层次、质感/粒子/氛围
8. **叙事完整性** — 检查叙事弧线覆盖度（开场→铺垫→发展→高潮→收尾）
9. **信息传达与可懂性** — 按 `references/comprehension-audit.md` 执行：盲审复述测试（遮掉台词/旁白/字幕，模拟零背景观众只凭画面复述故事）、静音/黑屏测试、枢纽事件可见性、通道冲突、依赖顺序、人物锚定。**本维度必须由独立视角执行盲审**（新会话 agent 或未接触过项目的审读者，只给画面栏），审查者自己读过全稿后做的"想象盲审"必须在报告中注明可信度降级。如果项目已有 `{标题}-观众认知时间线.md`（narrative-info-planner 产物），对照复查其结论是否在分镜中落实

### 第三步：评分

每个维度满分100分，根据 `references/shot-audit-rules.md` 中的扣分规则逐项扣减。

**加权总分计算：**

| 维度 | 权重 |
|------|------|
| **信息传达与可懂性** | **25%** |
| 提示词质量 | 15% |
| 节奏分析 | 12% |
| 景别分布 | 10% |
| 运镜多样性 | 8% |
| 构图意图 | 8% |
| 视觉连续性 | 8% |
| 色彩连续性 | 7% |
| 叙事完整性 | 7% |

**一票否决线**：信息传达与可懂性 < 60 分时，无论加权总分多少，总评级不得高于 C+，且结论不得出现"可放心生成/可进入生产"字样。工艺分不能买回观众的理解。

### 第四步：生成修改清单

将所有扣分项按优先级排序（扣分多的优先），生成具体修改建议。每条建议应包含：

- 涉及的分镜编号
- 具体问题描述
- **直接给出修改后的提示词文本**（而非抽象建议）

## 核心原则

1. **质量关卡** — 诚实但有建设性，指出问题的同时给出具体解法
2. **可操作性** — 所有建议都必须是可直接执行的，给出修改后的提示词而非抽象理论
3. **五大常见问题**（重点检查）：
   - **#1 旁白依赖症/画面失语**: 剧情信息全压在旁白/台词上，静音后画面讲不出故事；枢纽事件（杀人/背叛/相认/遗忘）不在画面内，只拍反应镜或用白光/黑幕替代。这是导致成片"讲不清楚故事"的最严重问题，工艺再好也救不回来
   - **#2 叙事节奏失速/体量注水**: 剪辑节奏健康但观众长时间得不到新东西——60 秒以上空窗、主转折压到后半场、放大/呼吸镜头占时超四成、时长超过拍点数×系数的合理体量。这是导致成片"节奏太慢、内容太简单"的最严重问题，镜头拍得再美也救不回来
   - **#3 风格尾缀同质化**: 所有镜头使用完全相同的风格/画质尾缀
   - **#4 时长均一化**: 所有镜头都是相同时长（如全部10秒），缺乏剪辑节奏变化
   - **#5 景别单调**: 过多中景镜头，缺少极端景别（ECU/LS）的视觉冲击

## 评级标准

| 等级 | 分数范围 | 含义 |
|------|---------|------|
| A+   | 95-100  | 专业级，几乎无需修改 |
| A    | 90-94   | 优秀，仅需微调 |
| B+   | 85-89   | 良好，有提升空间 |
| B    | 80-84   | 合格，建议修改 |
| C+   | 75-79   | 及格，需要修改 |
| C    | 70-74   | 勉强及格，多处需改 |
| D    | <70     | 不合格，建议重写 |

## 风格基因档案（可选对照标准）

若用户随分镜脚本一并提供《{标题}-风格基因档案.md》（来自 auteur-style-profiler），在审片报告中增加**风格一致性**对照检查：

- 逐维度核对分镜是否兑现档案第 3 节的"本片具体做法"（重点：色彩·光影、构图·运镜、剪辑节奏）
- 核对第 5 节标志性手法植入点是否在对应镜头落实
- 核对第 6 节负面清单是否被违反（出现了该风格下不该出现的元素）
- 发现风格漂移：列入修改建议，指向"按档案第 7 节下游消费指南重跑对应技能"——不修改档案本身，也不因风格偏好扣可懂性维度的分
