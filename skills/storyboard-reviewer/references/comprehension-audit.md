# 维度9: 信息传达与可懂性 — 审查协议与扣分规则

本维度回答一个问题：**一个零背景观众（没读过原著、不认识创作者、第一遍观看）能不能看懂这个故事。**

概念定义（信息资产/枢纽信息/四通道/呼吸镜头/二次触达）沿用 `narrative-info-planner` 技能的标准，详见其 `references/channel-rules.md` 与 `references/comprehension-checklist.md`。本文件只规定审片时的执行步骤与扣分规则。

## 执行步骤

### Step 1: 建立最小信息清单

从分镜脚本反推：零背景观众看懂主线必须知道的枢纽信息有哪几条（谁、想要什么、发生了什么关键事件、结局为何如此）。通常 4-7 条。若项目已有 `{标题}-观众认知时间线.md`，直接采用其信息资产清单，并把审查任务变为"复查落实"。

### Step 2: 盲审复述测试（本维度权重最大的证据）

1. 制作盲审材料：复制分镜脚本，删除所有台词栏、旁白栏、字幕栏、创作意图注释（"叙事功能""暗示XX"全删），只留镜号+时长+画面动作描述。
2. 交给独立视角执行——按可信度排序：
   - 新会话 agent，指令："只根据画面描述按顺序复述你看到的故事，不要脑补合理化，在看不懂处直接写'此处不明白'"
   - 未接触过项目的真人
   - 审查者本人的想象盲审（已读过全稿，天然带上帝视角）——结果必须标注"可信度降级"，且不得作为高分依据
3. 判读复述文本，标注三类问题：
   - **画面失语点**：复述丢失了枢纽信息（复述者没提，因为画面里没有）
   - **信息断点**：复述者明确写"不明白为什么"
   - **误导点**：复述者把因果脑补错了（比断点更危险——观众不会觉得没看懂，只会看懂一个错误的故事）

### Step 3: 静音 / 黑屏测试

- 剧情漫剧：遮掉全部声音信息，只走画面+字幕。主线因果链（枢纽事件序列）必须仍可跟随。
- 解说漫剧：①只读旁白，确认论述完整；②逐条核对旁白与同时段画面，打分`演/衬/离`（画面就是旁白内容的展开/相关但不承载/无关纯好看）。

### Step 4: 五项硬性检查

按 narrative-info-planner 的 `comprehension-checklist.md` 执行：枢纽事件可见性、内心活动转译、通道冲突、依赖顺序、人物锚定。

## 扣分规则（满分100，扣完为止）

### 致命项

| 问题 | 扣分 |
|------|------|
| 枢纽事件不可见（改变故事走向的事件只有反应镜/白光/黑幕/画外交代，事件本身不在画面） | 每处 **-25** |
| 盲审复述误导点（零背景视角把因果理解成了另一个故事） | 每处 **-20** |
| 盲审复述断点（枢纽信息画面失语，复述不出"谁对谁做了什么"） | 每处 **-15** |
| 剧情漫剧静音测试主线断裂 | 每段 **-15** |
| 解说漫剧画面`离`（配图化）占比 >20% | **-20**，>40% 再 **-15** |
| 关键角色零锚定（画外音角色无可见代理物；或双主角造型无区分且无同框确立） | 每人 **-15** |
| 悬空依赖（本镜理解所需的前置信息从未送达或晚于本镜送达） | 每处 **-10** |

### 严重项

| 问题 | 扣分 |
|------|------|
| 内心活动被当作镜头唯一信息增量（"他明白了"式支点，无外部动作转译） | 每处 **-8** |
| 通道冲突：旁白转述同镜/邻镜台词，或解说画面正在演的动作 | 每处 **-5** |
| 关键道具信息曝光不足（<3秒，或无角色反应镜确认"读到"） | 每处 **-5** |
| 枢纽名词（人名/项目名/事件名）仅单次触达即承担反转 | 每处 **-5** |
| 台词/旁白字数超时长承载（>5字/秒，或叠放超载） | 每处 **-3** |

### 一般项

| 问题 | 扣分 |
|------|------|
| 呼吸镜头超配额（>20% 或连续两镜） | **-5** |
| 抒情旁白挤占枢纽信息时间窗 | 每处 **-3** |
| 首集/独立短片缺开场信息锚（30秒内观众不知道"这是关于谁的什么事"） | **-8** |

### 加分参考（封顶100）

- 枢纽信息有跨通道二次触达设计（铺垫+确认）：每处 +3
- 存在配套 `观众认知时间线.md` 且分镜逐条落实：+5

## 与总分的关系

- 本维度权重 25%，全维度最高。
- **一票否决线**：本维度 < 60 时，总评级封顶 C+，结论禁用"可放心生成/可进入生产"。
- 修订版复审时，本维度必须重跑盲审（用修订后的画面栏重新做），不得沿用首审复述结果。
