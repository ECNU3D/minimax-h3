# 分镜审查清单 — 8维度详细标准

## 维度1: 景别分布

### 理想分布（通用标准）

| 景别 | 缩写 | 理想占比 | 核心含义 |
|------|------|---------|---------|
| 大特写 | ECU | 5-15% | 极度强调 — 情感爆发点、关键细节、符号隐喻 |
| 特写/近景 | CU | 15-25% | 情感表达 — 角色内心、反应、对话重点 |
| 中景 | MS | 30-40% | 叙事主力 — 动作交代、人物互动、剧情推进 |
| 全景 | FS | 15-25% | 动作/环境 — 完整动作展示、人物与环境关系 |
| 远景 | LS | 5-15% | 空间建立 — 世界观展示、场景过渡、氛围渲染 |

### 信号灯判定

**红灯（严重问题）：**
- 任一景别占比 > 50%
- ECU 或 LS 出现次数为 0
- 连续 3 个或以上镜头使用相同景别

**黄灯（需关注）：**
- 任一景别占比 > 40%
- 连续 2 个镜头使用相同景别

**绿灯：**
- 各景别占比在理想范围内
- 相邻镜头景别有跳切变化

### 判断方法

从提示词中提取景别关键词：特写、近景、中景、全景、远景、航拍、半身、头肩、面部、大特写等。映射规则详见 `shot-audit-rules.md`。

## 维度2: 运镜多样性

### 理想标准

- 至少使用 **4种** 不同运镜类型
- 无单一类型占比 > 35%
- 运镜选择与叙事情绪匹配

### 信号灯判定

**红灯：**
- 仅使用 2 种以下运镜类型
- 单一运镜类型占比 > 50%

**黄灯：**
- 仅使用 3 种运镜类型
- 单一运镜类型占比 > 35%

### 运镜与叙事对应关系

| 运镜 | 适用叙事情绪 |
|------|------------|
| 固定 | 平静、紧张等待、庄严、仪式感 |
| 推 | 逼近、发现、聚焦、压迫感、揭示细节 |
| 拉 | 揭示全貌、离别、失落、退出、显示规模 |
| 摇 | 环顾、巡视、展示空间关系、追踪运动 |
| 跟随 | 追逐、陪伴、动态叙事、角色视角 |
| 环绕 | 审视、展示关系、仪式感、关键时刻 |
| 航拍 | 宏观视角、世界观展示、史诗感、过渡 |
| 升/降 | 地位变化、揭示/隐藏、情绪起落 |
| 手持 | 纪实感、紧张、混乱、沉浸感 |
| 变焦 | 突然聚焦、震惊、荒诞、心理冲击 |

### 判断方法

从提示词开头提取运镜关键词。映射规则详见 `shot-audit-rules.md`。

## 维度3: 色彩连续性

### 有 VDD 时的审查项

1. **场景色彩匹配**: 检查每个镜头的色调描述是否匹配 VDD 中该场景的色彩地图
2. **角色色彩身份**: 角色出现时，其色彩身份标识（服装色、标志色）是否在提示词中被维护
3. **相邻镜头色温跳变**:
   - 同场景内：色温不应突变（暖→冷需要叙事理由）
   - 场景切换时：应有合理的色彩过渡或对比设计
4. **色彩叙事弧线**: 整体色彩变化是否与 VDD 设定的色彩弧线一致（如：冷→暖→冷→暖高潮）

### 无 VDD 时的审查项

- **风格尾缀同质化检查**: 是否所有镜头使用完全相同的风格/色彩尾缀
  - 如果是 → 严重扣分，因为不同场景/情绪应有不同的色彩处理
  - 应至少有 2-3 种色调变体
- **基本色彩逻辑**: 检查是否有明显的色彩矛盾（如：夜晚场景使用暖阳色调）

## 维度4: 构图意图

### 审查标准

每个镜头是否有超越"景别"的构图指导：

| 构图要素 | 说明 |
|---------|------|
| 空间层次 | 是否描述了前景/中景/背景的分层内容 |
| 人物位置 | 人物在画面中的位置（三分法、居中、边缘） |
| 光影方向 | 光从哪里来、投射方向、明暗对比 |
| 视线引导 | 是否有引导观众视线的设计（线条、色彩对比、运动方向） |
| 留白/负空间 | 是否有意义的空白区域设计 |

### 信号灯判定

**红灯：**
- 所有镜头无任何构图指导（仅描述人物+动作）

**黄灯：**
- 超过 50% 的镜头缺少构图指导

### 示例对比

**好的构图指导：**
> 苏小月位于画面左侧三分之一处，右侧大片空间留给门缝中透入的金色光线。前景是模糊的铁栅栏，背景是幽暗的走廊深处。光线从右上方45度角射入，在地面形成长条光斑。

**差的构图（仅叙事）：**
> 苏小月站在走廊里，看着门缝中的光线。

## 维度5: 节奏分析

本维度分两个子项：**5A 叙事节奏（占 2/3）+ 5B 剪辑节奏（占 1/3）**，维度分 = 5A×2/3 + 5B×1/3。两者是不同的东西：剪辑节奏是镜头时长的张弛变化，叙事节奏是观众获得新东西的频率——剪辑节奏满分不能买回叙事节奏（《好》教训：时长 7-15 秒错落有致，但 60 秒空窗×2、主转折 67%，观众反馈"太慢、太简单"）。

### 5A 叙事节奏审查标准（主项）

拍点定义、阈值、体量系数的唯一标准源：`../narrative-info-planner/references/beat-rhythm-rules.md`。执行"快速核算流程"：

1. **逐镜标注拍点类型**：信息拍 / 情绪拍 / 放大（核对挂靠）/ 呼吸。有 📌信息增量申报直接复用，但要**抽查伪增量**（同一事实的重复证明谎报成新信息）
2. **平均间隔**：全片时长 ÷ 独立拍点数，剧情 ≤45 秒、解说 ≤30 秒
3. **空窗地图**：任何连续 >60 秒无新拍点的段落逐段标红
4. **前 60 秒钩子**：主角是谁 + 当下情境 + 值得看下去的问题，三要素逐项核对；解说漫剧禁止格言体/主题句开场
5. **主转折位置**：≤50%（艺术片模式声明后 ≤60%）
6. **放大+呼吸配比**：时长占比 ≤40%、连续 ≤2 镜、挂靠 100% 有效
7. **体量核对**：N × 类型系数 vs 实际总时长，超上限 = 体量注水
8. 若脚本声明艺术片模式：核查媒介错配审查是否通过（情绪押在微表情/声线 = 声明无效）

### 5B 剪辑节奏审查标准（辅项）

1. **时长分布变化性**（最常见问题！）
   - 计算所有镜头时长的标准差
   - 理想：标准差 > 1.5秒，最长与最短差距 > 4秒
   - 红灯：所有镜头相同时长 / 标准差 < 1秒
   - 黄灯：标准差 1-1.5秒

2. **高潮段加速**
   - 高潮/紧张段落的镜头是否比平静段落更短
   - 动作场景：建议 3-6秒短镜头快切
   - 情感场景：建议 8-12秒慢镜头
   - 红灯：高潮段和平静段节奏完全一致

3. **呼吸空间**
   - 是否存在 8-12秒 的静态/固定镜头作为节奏缓冲
   - 连续快切后是否有"喘息"镜头
   - 红灯：全部快节奏无缓冲 / 全部慢节奏无高潮

4. **节奏曲线**
   - 整体应呈现波浪形：平缓→加速→缓冲→高潮加速→收尾放缓
   - 红灯：完全平坦的节奏线

## 维度6: 视觉连续性

### 审查标准

1. **同场景内一致性**
   - 光线方向：同一场景的多个镜头，光源方向是否一致
   - 角色位置：动作连续性，上一镜头角色在左，下一镜头不应突然在右（除非有切换理由）
   - 环境元素：场景内的道具/背景是否保持一致

2. **场景切换过渡**
   - 是否有过渡设计（如：推入细节→切→新场景拉出）
   - 硬切是否有叙事理由（时间跳跃、对比等）

3. **角色外观一致性**
   - 同一角色在不同镜头中的描述是否一致（服装、发型、特征）
   - 是否使用了一致的角色描述关键词

4. **时间连续性**
   - 时间线是否连贯：日出→正午→黄昏→夜晚
   - 如有时间跳跃是否有标注

## 维度7: 提示词质量

### 审查标准（按严重程度排序）

1. **风格尾缀差异化**（最严重！）
   - 检查所有镜头的风格/画质尾缀是否完全相同
   - 100% 相同 → 红灯，严重扣分
   - 不同场景/情绪应有不同的风格处理
   - 示例差异化：紧张场景用"高对比度, 低饱和度, 颗粒感"，温馨场景用"柔光, 暖色调, 浅景深"

2. **光线描述**
   - 是否每个镜头有具体的光线方向/色温/强度
   - 红灯：全部镜头无光线描述
   - 好的示例：「逆光，金色阳光从窗户45度角射入，人物面部半明半暗」
   - 差的示例：（无任何光线描述）

3. **纵深层次**
   - 是否有前景/中景/背景的分层描述
   - 红灯：全部镜头无纵深层次

4. **质感/纹理**
   - 是否有表面质感描述（皮肤、布料、金属、木材等）
   - 提升画面真实感的关键要素

5. **粒子/氛围**
   - 是否有大气效果描述（灰尘微粒、雾气、雨滴、光效、烟雾等）
   - 增加画面层次感和沉浸感

6. **声音/音效**（如平台支持）
   - 是否有环境音/音效描述
   - 非强制项，但有则加分

7. **声画分轨**（P0 硬伤，机械可查）
   判定细则见 `narrative-info-planner/references/audio-lane-rules.md`。前提：**只要提示词正文里出现带引号的话，会生成音频的平台就一定会配上语音。**
   - **🅑 人声写进正文**（红灯）：应后期录制的台词/旁白/广播/画外音/内心独白，其原文出现在代码块内。强制走 🅑 的五种情形：①品牌名/产品名/Slogan/必听信息；②画外音·广播·旁白·内心独白（无口型可对）；③需要精确卡点/响度/跨镜连续；④超出所在时间段容量；⑤脚本别处已写"必须后录"。
   - **双轨冲突**（红灯）：同一句话既在代码块内、又在块外被标为后录 → 模型配一条、后期录一条。
   - **台词超窗**（红灯）：`可容纳字数 ≈ (窗口秒数 − 0.4) × 语速`，语速取 快对白 5／正常对白 4.5／广告旁白 4／失真广播·强调句 3–3.5 字每秒；破折号省略号每处扣 0.3 秒、逗号扣 0.15 秒。同一把尺子验声音时间轴每一行。
   - **缺人声禁令**（黄灯）：有后录人声的镜，正文没写 `无人声、无对白、无旁白、无画外配音`，模型可能自作主张加一段嘟囔。
   - **写声音词而非可见动作**（黄灯）：`第二声脆响发生` → 应写 `牙齿清楚咬穿米果，碎屑轻微迸开`。注意 `第一声脆响后空气像停住` 同时还犯了跨镜引用。
   - 好的示例：正文 `墙上老式金属扬声器亮起一点电流指示光并轻微震动，他的扫帚立刻停住`＋块外 `🔊 音轨归属：🅑 后期录制｜台词全文"……"｜占 2.6–6.6 秒（跨镜1→2）｜预算 4.0 秒 ✅`
   - 差的示例：正文 `画外失真童声广播"请不要在戏院食用——小小酥"`（3-4 秒窗口）＋块外 `广播必须后录`

## 维度8: 叙事完整性

### 审查标准

1. **叙事弧线覆盖**
   - 是否覆盖完整弧线：开场→铺垫→发展→高潮→收尾
   - 各阶段是否有对应的镜头
   - 红灯：缺少高潮或收尾

2. **关键情节点**
   - 原始故事/剧本中的关键情节点是否都有对应镜头
   - 是否有遗漏的重要事件

3. **对话/旁白分配**
   - 对话和旁白是否合理分配在各镜头中
   - 是否有镜头承载过多文字信息

4. **角色出场/退场**
   - 主要角色的出场是否有建立镜头
   - 退场是否有交代
   - 红灯：角色突然出现/消失无铺垫

---

## 维度9: 信息传达与可懂性

审查标准、盲审复述协议、静音/黑屏测试与扣分规则见独立文件 `comprehension-audit.md`。

本维度与维度8的分工：维度8查"叙事弧线在脚本里齐不齐"（创作者视角的完整性），维度9查"零背景观众第一遍能不能接收到"（观众视角的可懂性）。脚本里信息齐全但全压在旁白、枢纽事件不可见、观众需要先验知识——维度8可能满分，维度9照样不及格。两个维度不得互相替代。
