# 四通道分工规则

观众接收故事信息只有四条通道：画面动作、台词、旁白、字幕。每条信息指定唯一主通道；枢纽信息允许（且默认需要）间隔性的二次触达，但禁止同镜双通道同述。

## 通道优先级判定

按顺序问三个问题，落在哪一层就用哪个通道：

1. **拍得出来吗？** 外部动作、物理事件、空间关系、道具状态 → **画面动作**。画面拍得出的信息用其他通道代替，视为画面失语。
2. **能从人物嘴里自然说出来吗？** 身份、动机、前史、规则，能进对话就进对话 → **台词**。注意"自然"：人物不会对彼此说双方都知道的事（"as you know" 禁令）——需要一个不知情的第三方、一次质问、一次翻旧账，来制造说出来的理由。
3. **两者都不行吗？** 时空跳跃（"三年后"）、画外前史、解说体裁的论点 → **旁白** 或 **字幕**。旁白说观点和跨度，字幕锚定时间地点人名头衔。

## 各通道使用规范

### 画面动作

- 剧情漫剧的第一通道。枢纽事件（杀人/背叛/发现/决定）只能走这条通道，其他通道只能补强不能替代。
- 一镜一个清晰节拍为默认；单镜超过 3 个信息节拍即过载（5 秒镜头超过 2 个即过载）。
- 关键道具信息（手机屏幕、信件、伤口）需要：≥3 秒稳定曝光 + 一个角色反应镜头做"读到确认"。

### 台词

- 每段台词标注功能：`推进`（送新信息）/ `人物`（塑造性格）/ `氛围`。连续两段纯氛围台词即冗余。
- 台词里的关键名词（人名、项目名、事件名）第一次出现时，观众是听不住的——枢纽名词必须有二次触达（隔一段后再次被提及，或配字幕）。
- 语速换算：中文 4-5 字/秒，加停顿按 3-3.5 字/秒排版。台词+旁白同镜叠放时先算总字数再定时长。
- **每句台词都要过时长预算，并盖 🅐 模型生成／🅑 后期录制的章**——`可容纳字数 ≈ (窗口秒数 − 0.4) × 语速`。窗口装不下就砍字、跨镜或换通道，不许靠"念快点"。完整规则见 `audio-lane-rules.md`：本文件决定"这条信息走哪个通道"，那份文件决定"走台词/旁白通道的那句话由谁发声、写在哪里、装不装得下"。

### 旁白

- **配额制**：剧情漫剧全片旁白承载的枢纽信息不得超过 2 条，且仅限"画面与台词都无法自然承载"的类型（时空跳跃、画外前史）。超配额 = 回去改画面和台词，不是改旁白。
- **禁令**：旁白不得转述画面正在发生的事（"他扣下扳机"式解说）；不得转述本镜台词；不得代角色宣布内心结论（"他这才明白……"）——内心结论要么转译成动作，要么让角色自己说。
- 解说漫剧例外：旁白是第一通道，但每条旁白必须绑定画面证据——画面在"演"旁白说的事。旁白讲到谁，画面就是谁；旁白讲因果，画面演因果。绑定不上的旁白段落，判定为配图，重写画面或重写旁白。
- 抒情金句限量：每 10 条旁白至多 2 条纯抒情，且抒情句不得占用枢纽信息的时间窗。
- **旁白、画外音、内心独白一律走 🅑 后期录制**：没有口型可对，视频模型只会给一个随机音色随机口音，且旁白通常要跨镜连续。旁白原文**一个字都不进平台提示词正文**，见 `audio-lane-rules.md`。

### 字幕

- 承担四类信息：时间地点跳转（"三年后·北京"）、人物首次出场的身份标签（"方浩｜副总裁"）、无法可视化的媒介内容（聊天记录、新闻标题）、片尾点题金句。
- 字幕是后期叠加，画面提示词继续保持"画面内不要文字"（Seedance 会写乱字），但分镜脚本必须在对应镜位标注字幕内容与出现时机——字幕是设计的一部分，不是后期救场。

## 人物锚定专项

- 观众对角色的记忆是"视觉标签 + 功能"，不是名字。设计每个角色时先回答：观众用什么词指代他？（"那个面试官""戴眼镜的哥哥"）指代词模糊 = 锚定失败。
- 关键角色首次出场三件套：清晰正脸镜头 ≥2 秒、身份标签（字幕/制服/道具/他人称呼）、一个专属视觉记忆点（发型/颜色/物件）。
- **画外音角色是最高风险等级**：只有声音的角色，观众留不下记忆槽位。若剧情需要隐藏面孔，必须给可见代理物（通话界面备注+头衔、聊天记录、他人转述其身份与动机），且名字在其发挥枢纽作用之前至少出现两次、两次间隔一个段落以上。
- 同性别同年龄段双主角（如双女主对峙戏）必须在造型上拉开至少两个维度（发型+服装色系），并在开场镜头里同框确立对位关系。

## 体裁速查

| | 剧情漫剧 | 解说漫剧 |
|---|---|---|
| 第一通道 | 画面动作 | 旁白 |
| 台词 | 第二通道，承载动机与关系 | 少量，作为画面证据的一部分 |
| 旁白 | 配额 ≤2 条枢纽信息 | 主干，但逐条绑定画面证据 |
| 字幕 | 时空锚 + 身份标签 | 金句留存 + 知识点强化 |
| 自测标准 | 静音可跟主线 | 黑屏可听懂 + 画面在演旁白 |
