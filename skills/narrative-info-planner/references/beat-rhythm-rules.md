# 叙事节奏与体量规则（拍点尺）

> 本文件是全管线"叙事节奏"的唯一标准源，由 narrative-info-planner 维护。
> 引用方：shot-rhythm-planner（第零步体量裁定）、storyboard-reviewer（维度5叙事节奏子项）、seedance 等平台分镜技能（📌申报的拍点类型）。
> 与 `channel-rules.md` 的分工：channel-rules 管"信息走哪个通道送达"，本文件管"信息以什么频率到达观众"。

## 为什么需要这把尺子

**剪辑节奏（镜头时长的张弛变化）≠ 叙事节奏（观众获得新东西的频率）。** 一部片可以镜头时长错落有致、剪辑节奏满分，但 60 秒没有一条新信息——观众的体感是"节奏太慢、内容太简单"。

历史教训（《好》，2026-07）：48 镜 436 秒，镜头时长 7-15 秒有变化、剪辑节奏健康，审核一路绿灯；但主反转落在全片 67% 处、两处 60 秒以上的叙事空窗、放大与呼吸镜头占时约四成——成片被观众一致反馈"节奏太慢、七分钟讲的内容很简单"。旧尺子只量剪辑节奏，量不出这些。

## 拍点定义（逐镜四选一）

每个镜头必须归入且仅归入一类：

| 类型 | 定义 | 判定标准 |
|------|------|----------|
| **信息拍** | 送达一条观众语言的新信息（信息资产表 I 编号的首次送达） | 看完这镜，零背景观众"知道了一件之前不知道的事" |
| **情绪拍** | 观众情绪状态发生转折的时刻 | 必须能写出"观众的情绪从 __ 变成 __"；首次震惊、首次泪点、关系反转算，"继续感动"不算 |
| **放大** | 重复证明一条已送达的信息 / 延续一种已建立的情绪，只加强度不加新知 | 必须标注挂靠对象："放大 I5"或"放大情绪拍 B8" |
| **呼吸** | 纯氛围 / 空间 / 留白，无信息无情绪转折 | 空镜、质感镜头、节奏缓冲 |

**独立拍点 = 信息拍 + 情绪拍。放大和呼吸不是拍点。**

判定铁律：

1. **同一事实的第 2、3 次证明是"放大"，不是新拍点。** 例：《好》里"他忘了名字但没忘关心"——推碗"你别烫着"是情绪拍（首次证明）；之后的"别生病""盖围巾"都是放大。
2. **警惕伪增量。** 创作者最常见的自欺是给放大镜头编一条观众语言的"新信息"（"观众知道他也会关心她的咳嗽"）。判定问题只有一个：**这一镜改变了观众对故事的理解吗？** 没有改变，就是放大。
3. 放大不是坏东西——情绪全靠放大镜头堆出来。坏的是**无挂靠的放大**（观众还不知道为什么要感动）和**超配额的放大**（本金不够，利息透支）。

## 硬性指标

剧情漫剧默认值：

| 指标 | 阈值 | 说明 |
|------|------|------|
| 独立拍点平均间隔 | ≤45 秒 | 全片时长 ÷ 独立拍点数 |
| 最大空窗 | ≤60 秒 | 空窗 = 连续无新拍点的时长（放大/呼吸都计入空窗） |
| 前 60 秒钩子 | 必须完成 | 60 秒内观众已知：主角是谁 + 当下情境 + 一个值得看下去的悬念或问题。三缺一即不完整 |
| 主转折位置 | ≤50% 时长处 | 全片最大的一次认知反转 |
| 放大+呼吸时长占比 | ≤40% | 超过即"情绪透支"：利息（情绪）超过了本金（信息） |
| 连续放大/呼吸 | ≤2 镜 | 第 3 镜起逐镜累计违规 |
| 放大挂靠有效性 | 100% | 每个放大镜头挂靠的信息/情绪拍，必须在它之前 60 秒内送达或复达过 |

解说漫剧调整：

- 前 60 秒必须回答"讲谁、发生了什么事、为什么值得听下去"——**禁止格言体/主题句/哲学概念开场**，先给故事再给道理（《局外人》式的"没头没尾"就是这一条的反面教材）；
- 独立拍点平均间隔收紧到 **≤30 秒**——解说体裁的存在理由就是信息密度；
- 每条旁白必须绑定画面证据（见 channel-rules），旁白连续 2 条不含新信息即计入空窗；
- 结构与通道分工走 `explainer-formula.md`（悬念前置六步法）。其中"计数/收集框架"是把顺叙铺垫段的放大镜转化为信息拍的标准手段——密度不够时优先加框架，而不是删镜头。

## 艺术片模式（显式豁免条款）

若创作者刻意选择文艺慢节奏（对标电影节短片而非短视频信息流），必须在文档头部显式声明**艺术片模式**，并接受两个代价：

1. 阈值放宽有限：平均间隔 ≤60 秒、主转折 ≤60%、放大+呼吸 ≤50%——不是无限豁免；
2. **必须回答媒介错配问题：本片的情绪重量押在哪个通道？** 若答案是"微表情 / 眼神 / 声线表演"，AI 生成无法交付这个通道（渲染出来是标准脸），判定为媒介错配，退回选题层改设计——把情绪转译到道具、动作、仪式、空间等可生成通道上，才允许继续。

未声明而超标 = 按默认值扣分。声明了但媒介错配问题答不过 = 声明无效。

## 体量系数表（时长必须被推导，不允许被指定）

**目标时长 = 独立拍点数 N × 类型系数。** 剧本或用户提案里写的时长只是提案，必须先过这一关。

| 体裁 | 系数（秒/拍） | 说明 |
|------|--------------|------|
| 短剧/爽感向 | 25-35 | 事件驱动，快进快出 |
| 剧情漫剧（默认） | 25-40 | 情感浓度高的题材取上限，事件驱动取下限 |
| 艺术片模式 | 40-55 | 须显式声明并通过媒介错配审查 |
| 解说漫剧 | 15-30 | 信息密度驱动 |

用法：

1. 数出独立拍点数 N（重复证明合并计 1，放大/呼吸不计）；
2. 合理时长区间 = [N × 系数下限, N × 系数上限]；
3. 提案时长 **超过区间上限**：默认**裁时长**；只有当上游愿意加新剧情（新拍点，不是新镜头）时才允许保时长。**禁止用放大/呼吸镜头填满差额——这正是"节奏太慢"被制造出来的过程**；
4. 提案时长远低于区间下限（<N × 15 秒，剧情漫剧）：信息过载预警，回信息资产表做减法，并让维度9复查依赖顺序。

例（《好》）：独立拍点 11 个 × 25-40 秒 = 合理体量 4.6-7.3 分钟，情感题材取中值约 5-5.5 分钟；实际成片 7.3 分钟贴死上限，且多出的时长全部是放大与呼吸（占比超 40%）、两处 60 秒空窗、主转折 67%——体量勉强贴线 + 分布全面超标，综合判定：裁到 5 分钟左右。

## 快速核算流程（任何引用方通用）

1. 逐镜标注拍点类型（有 📌 申报直接用，没有则按定义自行判定）；
2. 数 N、算平均间隔、画空窗地图（每段空窗的起止秒数与时长）；
3. 核对前 60 秒钩子三要素、主转折位置百分比；
4. 算放大+呼吸时长占比、最长连续放大/呼吸段、逐个核对放大挂靠；
5. 用 N × 系数表核对体量；
6. 违规项逐条列出：位置（镜号/秒数）、超标量、修法（删/合并/前移/注入新拍点）。
