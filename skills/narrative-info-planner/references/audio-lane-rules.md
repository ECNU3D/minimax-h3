# 声画分轨规则（台词／旁白／广播写不写进提示词）

> 被 `seedance-storyboard`、`hailuo-storyboard`、`vidu-storyboard`、`wanxiang-storyboard`、`storyboard-reviewer`、`release-gate` 共用。
> 上游 `channel-rules.md` 决定"这条信息走哪个通道"；本文件决定"走台词/旁白通道的那句话，由谁发声、写在哪里、装不装得下"。

## 0. 事故原型

《请不要把童年吵醒》镜 1（2026-07）：

- 提示词正文写了 `画外失真童声广播"请不要在戏院食用——小小酥"`
- 同一镜的「声音／后期」栏又写了 `广播必须后录`
- 而这句话被放进 `3-4秒` 一个 **1 秒** 的窗口里

三个错各自独立、后果叠加：模型照写生成了一条自己的配音（音色随机、可能吞字改词），后期又录一条 → 同一句话两个声源；1 秒窗口装不下 11 个字 → 模型只能加速、糊字或干脆截断；而"必须后录"这句话写在代码块外，复制粘贴时根本不会进入平台。

**根因**：一句人声没有被明确"盖章"归属到某一条轨上，就会同时出现在两条轨上，并且没人给它算过时长。

## 1. 前提（必须先接受）

**会生成音频的视频模型（即梦 Seedance 2.0、通义万相 2.6、海螺等），只要提示词正文里出现带引号的话，就一定会给它配上语音。** 写了就会响，没有"它应该懂我只是描述一下气氛"这回事。

推论：提示词正文里的每一个引号，都是一次**下单**，不是一次说明。

## 2. 盖章：每一句人声只能有一个来源

写任何一句台词／旁白／广播／画外音／内心独白之前，先二选一盖章，并把章标在脚本里。

### 🅐 模型生成（写进提示词正文）

适用：**画面内人物开口说话、需要口型对上、且这句话不承担品牌必听信息**。

必须同时满足：

1. 台词原文写进正文，且**绑定到具体时间段**（`2-4秒：她看向对方，自然开口："……"`），不能只丢在段末；
2. 通过第 3 节的**时长预算**；
3. 说话人在画面内、有可见口型（画外音没有口型可对，模型只会给随机音色，一律走 🅑）；
4. 正文里补一句口型要求：`口型与中文台词一致`。

### 🅑 后期录制（一个字都不许进提示词正文）

**命中以下任意一条，强制走 🅑：**

| # | 情形 | 原因 |
|---|---|---|
| 1 | 品牌名／产品名／Slogan／必听信息 | 模型发音会吞字、改词、读错品名，赛事片一次错读即废 |
| 2 | 画外音、广播、旁白、内心独白 | 没有口型可对，音色/口音/年龄全随机 |
| 3 | 装配规范「必听台词清单」里的句子 | 需要精确入点、精确响度、跨镜连续 |
| 4 | 该句时长超过所在时间段的容量 | 模型会加速吞字或截断 |
| 5 | 脚本任何一处已写「必须后录／后期配音」 | 已经盖过 🅑 章，正文里再写就是双轨冲突 |

🅑 的提示词正文**只能写声源的可见物理动作**，不写一个字的台词：

- ❌ `老扬声器突然通电，画外失真童声广播"请不要在戏院食用——小小酥"，程野的扫帚停住`
- ✅ `画面右后方墙上的老式金属扬声器亮起一点橙色电流指示光并轻微震动，程野的扫帚立刻停住，肩膀微收`

并在同一条提示词的禁令段写死：`无人声、无对白、无旁白、无画外配音，人物不开口说话`。
（不写这句，模型仍可能自作主张加一段听不懂的嘟囔。）

台词原文只出现在三个地方，全部在**代码块之外**：代码块外的「声音／后期」行、声音时间轴、装配规范的必听台词清单。

### 盖章的落地写法

每条有人声的镜，在代码块外写一行：

```
🔊 音轨归属：🅑 后期录制 ｜ 台词全文"……" ｜ 占 2.6–6.6 秒（跨镜1→2）｜ 预算 11字+1破折号@3.3字/秒=4.0秒 ✅ ｜ 提示词正文已写"无人声、无画外配音"
🔊 音轨归属：🅐 模型生成 ｜ 台词全文"……" ｜ 绑定 2-6 秒 ｜ 预算 18字@4.5字/秒=4.4秒 ✅ ｜ 正文已写"口型与中文台词一致"
```

## 3. 台词时长预算（🅐🅑 都要算）

中文语速基准：

| 场景 | 字/秒 |
|---|---|
| 快节奏对白、争吵、崩溃喊话 | 5 |
| 正常对白 | 4.5 |
| 广告旁白、品牌收束、温暖叙述 | 4 |
| 失真广播、强调句、一字一顿、老人说话 | 3–3.5 |

```
可容纳字数 ≈ (时间窗秒数 − 0.4) × 语速
                          ↑ 起音呼吸 0.2s + 尾留白 0.2s
破折号／省略号／明显停顿：每处再扣 0.3 秒
逗号：每处再扣 0.15 秒
```

自检示范：

- `「请不要在戏院食用——小小酥」` 11 字 + 1 破折号，失真广播 3.3 字/秒 → 11/3.3 + 0.4 + 0.3 ≈ **4.0 秒**；写在 `3-4秒`（1 秒窗口）→ **❌ 超 3 秒**
- `「我想讲的不是更快，是怎么把节奏顺回来。」` 17 字 + 1 逗号，正常对白 4.5 字/秒 → 17/4.5 + 0.4 + 0.15 ≈ **4.3 秒**；绑定 `2-6秒`（4 秒）→ **⚠️ 紧，改绑 2-6.5 秒或砍 2 字**

**⚠️ 预算算的是「成片窗口」，不是「生成时长」。** 很多脚本按 `生成 10s / 成片 5s` 的方式做（生成长一点再截取），台词写在提示词的 `0-10秒` 里看着很宽裕，但观众只看得到剪进去的 5 秒——**必须拿成片时长去算预算**，并写明这句话落在生成素材的哪一段、剪辑取的就是那一段。生成窗口够、成片窗口不够，等于没算。

**装不下时的三条出路，禁止靠"加快语速"硬塞：**

1. **砍字** —— 把句子改短到预算内（首选；台词超预算通常也意味着写长了）；
2. **跨镜** —— 让尾巴跨过剪辑点延续到下一镜（只有 🅑 能这么干；必须在声音时间轴写明跨镜区间，且下一镜提示词同样不出现台词原文）；
3. **换通道** —— 改成后期字幕／卡字／可见动作（回 `channel-rules.md` 重新分配通道）。

**声音时间轴自检**：时间轴每一行的窗口必须 ≥ 该句预算秒数。窗口比预算短，就是时间轴本身写错了，不是"到时候念快点"。

## 4. 音效（非人声）同理但从宽

`咔嚓`、`哒哒`、脚步、关门声这类音效，如果全片声音走后期设计（"模型原声只作氛围参考"），提示词正文里也不要写声音词，写**产生这个声音的可见物理动作**——这本来就是更好的提示词工艺：

- ❌ `1.5-2秒：清楚咬下，第二声脆响发生`
- ✅ `1.5-2秒：牙齿清楚咬穿米果，碎屑轻微迸开`
- ❌ `0-1秒：后方先传来放映机机械"哒"的动作暗示`
- ✅ `0-1秒：画面后上方暗部的浮尘开始被一种规律的轻微震动带出细小抖动`

顺带消掉一个常见错误：`第一声脆响后所有空气像停住` 同时犯了"写声音"和"跨镜引用"（模型没看过上一镜，不知道有过第一声）。

## 5. 写完自检（三步，机械执行）

1. **搜引号**：把每个提示词代码块单独拎出来，搜 `"` `“` `「`。每命中一处，回答"它是 🅐 吗？过预算了吗？"——答不上就是错。
2. **搜声轨词**：搜 `旁白`｜`广播`｜`画外音`｜`配音`｜`独白`｜`后录`｜`后期配音`。代码块**内**命中这些词，基本都是错的。
3. **搜矛盾**：同一句话是否既在代码块内、又在"声音／后期"或装配规范里？出现两次 = 双轨冲突，删掉代码块内那份。

## 6. 审片与验收侧的对应查项

- `storyboard-reviewer`：脚本层查①代码块内是否出现应后录的人声原文；②每句台词是否有时长预算且不超窗；③声音时间轴窗口是否 ≥ 预算。
- `release-gate` 模式 A：装配规范必须有「音轨归属表」，逐句标 🅐/🅑 + 时间窗 + 预算。
- `release-gate` 模式 B：素材验收增加一查——**🅑 镜的生成音轨里不该有人声**。听到模型自己配的话，说明提示词漏改，该镜重生成（不是"后期把音轨静音就行"，模型配音时经常连带生成口型和错误的表演节奏）。
