# 解说漫剧结构配方（悬念前置法）

> 本文件是全管线"解说漫剧结构"的唯一标准源，由 narrative-info-planner 维护。
> 引用方：narrative-info-planner（体裁差异→解说漫剧）、seedance 等平台分镜技能（解说漫模式）、storyboard-reviewer（维度5A/9 解说漫审查）、release-gate（K 卡清单）。
> 实证来源：《局外人》2026-07-11 重构——旧版（时间顺序平铺，旧尺子 ~A）三项独立盲测判定"没头没尾"；按本配方重构后，黑屏测试复述完整、观众想读原著、静音可懂度 35→70。以下每条规则都对应一个被测出的具体失败。

## 为什么解说漫需要单独的结构配方

解说漫最自然的写法——按时间顺序把故事讲一遍、段尾配金句升华——恰好踩中它的两大死穴：

1. **观众不知道为什么要听**：最强的事实按时间顺序总是出现在后半段（《局外人》"判死刑理由是没哭"埋在 70% 处，测试观众 35-45 秒划走）；
2. **道理没人接得住**：铺垫段在观众眼里是闲笔（"所以呢？"），金句在没有故事支撑时是噪音（"温柔的冷漠"="像被文艺地糊弄过去了"）。

## 六步配方

### 1. 冷开场钩子（0-12 秒）

全片**最反常、最强的那个事实**第 0 秒送达；名著/IP 改编在钩子后立即亮书名卡（价值主张：观众要知道自己在看什么、看完能带走什么）。

- 禁止按时间顺序从头讲起；禁止格言体/主题句/时代背景介绍开场。
- 自检：陌生人听完第一句会不会追问"这怎么可能？"——不会，就还没找到钩子。
- 例：「一个男人杀了人。但检察官请求判他死刑的理由，不是那把枪——是他在母亲的葬礼上，没有哭。」

### 2. 命名与锚定（≤20 秒）

- 主角必须有名字：旁白说出 + 名牌字幕（《局外人》旧版 14 段旁白全用"他"，被测出"最实在的一个空缺"）。
- 配角用**功能称呼**锚定（"信里那个女人的哥哥"），不用观众记不住的专名、头衔或族裔标签；关键配角在其枢纽戏之前至少被指称两次。

### 3. 计数/收集框架（顺叙段的任务感）

给顺叙铺垫段一个观众任务框架——罪证一二三 / 线索收集 / 倒计时 / 三次机会：

- 框架把铺垫镜从"放大/闲笔"转化为框架下的**新信息拍**（拍点尺意义上的密度提升），观众"像在收集线索"，静音观众靠角标也能跟上；
- **只许一套计数系统**。两套并行必混——《局外人》v2 曾同时用"罪证一二三"和"第 N 次拒绝表演"，独立测试反馈"分不清是不是一回事、第一次没处倒推"；修法：前段只数一套，收束处一句点破两者同一（"三条罪证，其实是同一条罪"），再用排比替代第二套编号。

### 4. 枢纽可见 + 判决上卡

- 解说漫**不豁免**枢纽事件可见性：杀人要看见倒下（剪影/远景可以，白光黑幕不行）；
- 判决、结局、关键数字这类枢纽信息必须走**字幕卡**通道——这是静音观众的最大盲区（《局外人》盲审："判了死刑还是无期，画面没给"）。

### 5. 先白话，后引文（抽象结论的翻译义务）

任何哲学概念、抽象结论、原著金句，必须**先用观众语言翻译，后给原句**，顺序不可反：

- 例：先"这个世界从来不关心任何人。正因为谁都不被关心——谁也就不欠谁一场表演"，后"他把这叫做'世界温柔的冷漠'"。实测从"没懂"变为观众能用自己的话正确转述。
- 每段旁白末尾**禁止无脚手架的升华句**——升华句必须绑定它前面 30 秒内的具体事件。
- 全片最难懂的一句，优先考虑"把它翻译成主题的一部分"而不是删掉：《局外人》"因为太阳"→"没人信。可他宁愿说荒唐的实话，也不编一个体面的谎"——最大的问号变成了主题的又一次证明。

### 6. K 卡清单（卡字兜静音底）

解说漫标配五类后期卡，写进分镜脚本并进 release-gate 装配规范的禁删清单：

| 卡 | 内容 | 依据 |
|----|------|------|
| 书名卡 | 「作者《书名》· 年份」 | 价值主张+带走物 |
| 名牌 | 主角名 | 人物锚定 |
| 计数角标 | 框架计数（罪证一…） | 静音观众的框架入口 |
| 枢纽卡 | 判决/结局/数字 | 静音最大盲区 |
| 片尾引文卡 | **优先用原作者自己的话** | 《局外人》实测：加缪原话卡是全片信息增量最大的一张——"一句话把前面所有莫名其妙的镜头全串起来了"；静音可懂度 35→70 的主要功臣 |

## 通道三层分工（解说漫版）

**旁白讲因果与计数，画面演事件，卡字兜静音底。** 旁白禁止解说画面正在演的动作；画面事件层追求"演"率 100%（可做到——《局外人》旧版已 14/14）；意义层不指望画面，交给旁白翻译+尾卡点破。

## 验收标准（生成前脚本层，三个独立测试）

1. **黑屏测试**：零背景 agent 只听旁白——复述完整、说得出书名/作者/主角名、抽象结论能用自己的话转述；
2. **纯画面+卡字测试**：静音可懂度自评 ≥65（纯画面基线通常 30-40，卡字必须把它救回来）；
3. **前 60 秒钩子**：三要素齐（讲谁/发生了什么/为什么值得听），且第一句非格言体。

配套硬指标见 `beat-rhythm-rules.md` 解说漫剧调整（拍点间隔 ≤30 秒等）。
