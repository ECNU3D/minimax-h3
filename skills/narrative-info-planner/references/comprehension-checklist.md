# 五项硬性检查与自测协议

## 检查 1：枢纽事件可见性

对信息资产清单里每条`当下事件`类枢纽信息问：

- 这个事件在哪一镜？画面里能看到什么外部动作？
- 一个听不懂中文的观众，看这一镜能知道"发生了什么类别的事"吗（有人死了/有人走了/东西被拿了）？
- 艺术化处理（白光、剪影、画外）是叠加在可见动作之上，还是替代了它？

**判定**：枢纽事件无可见外部动作 → ❌，必须改。合规写法示例：不拍血腥可以，但"开枪"至少要有：持枪入画 → 枪口指向可见的对象 → 击发（声音+后坐）→ 对象倒下/失去动作。四拍缺一，事件不成立。

## 检查 2：内心活动转译

全稿搜索以下句式，出现即标记：

- "他明白了 / 意识到 / 想起了……"
- "他下定决心 / 释然了 / 崩溃了（无外部动作跟随）"
- "两人心照不宣 / 摸清了底牌 / 达成默契"
- "暗示 / 隐喻 / 象征着……"（当它是该镜唯一的信息增量时）

每处标记三选一：

1. 转译成外部动作（想起母亲 → 摩挲母亲的遗物；下定决心 → 删掉求饶短信草稿）
2. 转译成台词（让角色说出来，需符合"自然说出"规则）
3. 删除（这个内心节拍对主线不是必需）

## 检查 3：通道冲突

- 逐镜比对旁白栏与台词栏：旁白是否转述了同镜或邻镜的台词？→ 删旁白，留台词。
- 逐镜比对旁白栏与画面栏：旁白是否在解说画面正在演的动作？→ 删旁白。
- 台词是否在解释画面已经演清楚的事？→ 删台词或改画面。

## 检查 4：依赖顺序

对时间线表每一行的"依赖前置"列：

- 依赖的信息编号，其送达镜号是否严格早于本镜？
- 送达通道是否可靠（一句 8 秒前一闪而过的台词提到的名词，不算可靠送达——见 channel-rules 的二次触达规则）？
- 悬空依赖清单必须清零才能交付。

## 检查 5：人物锚定

每个关键角色过一遍 channel-rules 的"人物锚定专项"三件套；画外音角色单独列高风险项并给代理物方案。

## 盲审复述协议

目的：模拟"零背景观众第一遍观看"，是全流程唯一接近真实观众的检验。

执行规则：

1. **材料准备**：复制分镜脚本，删除所有旁白栏、台词栏、字幕栏、创作意图注释（"叙事功能""暗示XX"全删），只留镜号+时长+画面描述。
2. **审读者选择**（按可信度排序）：
   - 没接触过该项目的真人；
   - 新开会话的 agent（明确指令：只根据画面描述，按顺序复述你看到的故事，不要脑补合理化，在你看不懂的地方直接写"此处不明白为什么"）；
   - 创作者本人自测——结果只能作参考，文档中必须注明。
3. **判读**：复述与原意的偏差点=画面失语点；复述者写"不明白"处=信息断点；复述者脑补错误的因果=误导点（比断点更危险）。
4. 剧情漫剧的及格线：仅凭画面能复述出"谁、做了什么、结果如何"的主线骨架。

## 静音 / 黑屏测试协议

- **剧情漫剧（静音测试）**：遮掉全部声音信息（台词/旁白/音效说明），只看画面栏+字幕栏走一遍。主线因果（枢纽事件链）必须仍可跟随。允许丢失：动机细节、情感层次。不允许丢失：谁对谁做了什么。
- **解说漫剧（黑屏测试 + 绑定核对）**：
  1. 只读旁白栏：论点/故事是否完整连贯（应当是——这是解说体裁的主干）；
  2. 逐条核对旁白与同时段画面：画面在"演"这条旁白吗？打分：`演`（画面就是旁白内容的展开）/ `衬`（画面相关但不承载）/ `离`（画面与旁白无关，纯好看）。`离`超过 20% 判定为配图片。
