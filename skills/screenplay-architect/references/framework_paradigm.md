## 电影剧本的本质

> "电影剧本是由画面、对白和描述来讲述的故事, 并将所有这些安置在戏剧性结构的情境脉络之中。"

**核心特征**:
- 长度: ~120 页 (一页约等于一分钟银幕时间)
- 介质: 用视觉讲故事 (visual storytelling), 不是文学
- 与小说/戏剧的根本区别:
  - **小说**: 戏剧动作在主角脑海里
  - **戏剧**: 戏剧动作在舞台上, 通过语言展现
  - **电影**: 视觉化, 通过画面、动作、声音传递信息
- 与诗歌更相近: 严格遵循一条明确、精炼、紧凑的情节叙事线

**故事是 What + Who**:
- **主题 (Subject/Theme)**: 故事讲的是关于"什么事"
- **情节 (Action)**: 发生了什么
- **人物 (Character)**: 涉及什么人

> "在你能够落笔书写第一个字之前, 你必须知道你的故事是有关什么事和什么人的。"

## 写作前必知的根本问题

### 五大根本问题
1. 这个故事是关于谁的？(主要人物)
2. 这个故事讲的是什么？(主题/前提)
3. 故事发生在什么环境里？(戏剧性情境)
4. 主角想要什么？(戏剧性需求)
5. 谁阻挡他得到？(对抗力量/冲突)

### 四个固置点
在动笔写第一个字之前, **必须**知道以下四件事:

> "在你打算开始写你的第一个字以前, 你就必须知道四件事情: 你的结尾、你的开端、情节点 I 和情节点 II。"

详见 [`four_cornerstones.md`](four_cornerstones.md)。

### 写作核心难题
> "写作最难的事情就是知道要写些什么内容。"

> "如果连你都不知道你的故事讲了些什么, 那谁还会知道呢？"

## 三幕式结构范式

| 幕 | 篇幅 | 戏剧性情境脉络 | 核心功能 |
|----|------|--------------|--------|
| **第一幕** | 约 20-30 页 | **建置 (Setup)** | 引介主角、建立前提、设置情境 |
| **第二幕** | 约 50-60 页 | **对抗 (Confrontation)** | 障碍与冲突, 戏剧性需求受到考验 |
| **第三幕** | 约 20-30 页 | **结局 (Resolution)** | 解决冲突, 完成转化 |

幕与幕之间通过**情节点 (Plot Points)** 衔接:
- **情节点 I**: ~p.20-27, 真正的故事开端
- **情节点 II**: ~p.80-90, 推入第三幕的最终转折

### 第一幕: 建置
> "在电影剧本最前面的二十到三十页里, 你必须建置你的故事。"

必须建立:
- 主要人物 (who)
- 戏剧性前提 (what)
- 戏剧性情境 (周边环境, where/when)
- 人物之间的关系 (职业生活、个人生活、私生活)

> "从第一页、第一个词起, 你就必须尽快地建置起你的故事。"

### 第二幕: 对抗
> "所有的戏剧都是冲突。没有冲突就没有情节, 没有情节就没有人物, 没有人物你就不会有故事, 而没有了故事你也就不会有电影剧本。"

> "如果你知道你的人物的戏剧性需求, 然后你能够设置障碍去阻碍这种需求的实现, 你的故事就成为了你的人物去克服重重阻力以成就他(她)的戏剧性需求。"

第二幕是篇幅最长、最难写的部分。详见 [`act_two.md`](act_two.md)。

### 第三幕: 结局
> "结局的意思就是'寻求一种解答; 解释清或者澄清; 分解成为各种独立的元素或部分'。它不是你故事的结尾, 它是你剧本的解决方案。"

> "假如你并不知道如何解决你的故事, 问一下你自己'我希望它是个怎样的结局', 不要在意它的效果将会怎样, 或'别人'对它是否喜欢。这是你自己的故事, 所以你必须弄清楚怎样去结束故事。而且这将是你的起始点。"

详见 [`act_three.md`](act_three.md)。

## 范式图解

```
                       一百二十页 (120 minutes)
   ┌──────────────┬───────────────────────────────────┬──────────────┐
   │   第一幕      │           第二幕                  │   第三幕     │
   │  建置 SETUP   │       对抗 CONFRONTATION          │  结局        │
   │  20-30 页     │           50-60 页                │  20-30 页    │
   │              ⬢                  ⬣                  ⬢             │
   │              情节点 I          情节点 II                          │
   │              ~p.20-27          ~p.80-90                          │
   └──────────────┴─────────────────┬─────────────────┴──────────────┘
                                    ⬡
                                  中间点
                                  ~p.60

   隐藏支撑点:
   - 紧要关头 I (~p.45)
   - 紧要关头 II (~p.75)

   情节点 = 任何"钩住"情节并将其转向另一个方向的事变、插曲或事件
```

|---------|---------|-----|
| 范式 | Paradigm | 电影剧本结构的模型/路线图 |
| 戏剧性结构 | Dramatic Structure | 对一系列相互关联的事变进行线性安排, 最终导致戏剧性结局 |
| 情境脉络 | Context | 容纳故事内容的框架 (建置/对抗/结局) |
| 主题 | Subject/Theme | 故事的灵魂, 创作的起点 |
| 戏剧性前提 | Dramatic Premise | 故事的内容是关于什么 |
| 戏剧性需求 | Dramatic Need | 主角想要赢得、得到、获取或成就的某种东西 |
| 戏剧性情境 | Dramatic Situation | 动作发生的周边环境 |
| 矛盾冲突 | Conflict | 所有戏剧的本质 |
| 障碍 | Obstacle | 阻碍戏剧性需求实现的力量 (内/外, 身/心, 情感/理智) |
| 情节点 | Plot Point | "钩住"情节并转向的事变/插曲/事件 |
| 情节点 I | Plot Point I | 第一幕末, 故事的真正开端 |
| 情节点 II | Plot Point II | 第二幕末, 推入第三幕 |
| 中间点 | Midpoint | 第二幕中央的链接事件 |
| 紧要关头 | Pinch Point | 中间点前后的"推力"段落 |
| 建置 | Setup | 第一幕的情境脉络 |
| 对抗 | Confrontation | 第二幕的情境脉络 |
| 结局 | Resolution | 第三幕的情境脉络, 故事的解决方案 |
| 人物特征 | Character | 人物的深层本性 (价值观、行为操守、信仰) |
| 人物塑造 | Characterization | 人物如何向外展示自己 (服饰、爱车、品味) |
| 解说 | Exposition | 推动故事或揭示人物所需的信息 |
| 潜台词 | Subtext | 场景里"没有说出口的内容" |
| 蒙太奇 | Montage | 由单一构想连接的视觉性系列场景 |
| 闪回/闪现 | Flashback / Flash-Present | 用于揭示信息或推动情节的时间工具 (人物在现在时刻对过去的体验) |

## 范式柔韧性: 工具而非教条

> "范式仅仅是一个模式、一个样板或概念方案, 它并不是用来依样画葫芦的东西。"

> "结构的美妙之处就在于它的柔韧性: 就像一棵大风中的树那样, 它可以折腰但不会折断。"

页码是参考, 不是规则:
- 情节点可以在 ±3-5 页范围内浮动
- 非线性叙事 (《低俗小说》《英国病人》《记忆碎片》) 仍遵守三幕本质
- 形式可变, 内核不变: 主角、需求、障碍、转化、解决

### 线性 vs 非线性
- **线性**: 《杯酒人生》《教父》——故事按时间顺序推进
- **非线性**: 《低俗小说》《时刻刻刻》《谍影重重 2》《英国病人》——内核仍是三幕
- **书档式 (bookend)**: 《廊桥遗梦》《公民凯恩》《日落大道》——以现在事件框住整个回忆故事

威廉·戈德曼: "电影剧本就是结构, 它是维系你故事的脊椎。"

## 菲尔德的金句原则

**关于电影本质**:
> "一部电影剧本是一个特殊的形式。它是一个用画面来讲述、用对白和描写来表现的故事。"

> "现在, 我们生活在一个用视觉讲故事的时代。"

> "故事的表现是通过展示而不是告诉; 人物的揭示是通过行为而不是对白。"

**关于结构**:
> "好的结构就像你剧本的脊椎、基础和无形的凝合剂。它妥善地'掌握'了故事, 就像置入螺钉将绘画挂在墙上一样。"

> "对于所有优秀的电影剧本来说, 有一点是共同的, 那就是结构。"

**关于过程**:
> "电影剧本写作是一个逐步推进的过程。"

> "若存疑虑, 切忌盲动。"

> "完美无缺只存在于头脑里, 而不是在现实世界中。" ——让·雷诺阿

> "艺术就是实践。" ——让·雷诺阿

**关于创作准备**:
> "写作就是不断地改写。"

> "你必须容许自己犯错误, 否则你不可能学到任何东西。"

**关于结尾先行**:
> "在你打算开始写你的第一个字以前, 你就必须知道四件事情: 你的结尾、你的开端、情节点 I 和情节点 II。"

> "通常写作的首要步骤总是要知道结局。"

## 引用案例 (用于范式分析)

学习范式最有效的方式: 选 2 部影片反复观看 3 遍, 用秒表标记结构点。推荐影片:

| 影片 | 适用学习 |
|------|--------|
| 《杯酒人生》(Sideways) | 线性叙事、主题简洁 |
| 《时刻时刻》(The Hours) | 非线性多线索结构 |
| 《末路狂花》(Thelma & Louise) | 强力情节点、人物驱动 |
| 《英国病人》(The English Patient) | 书档式闪回结构 |
| 《普通人》(Ordinary People) | 三个十页的精确建置 |
| 《借刀杀人》(Collateral) | 人物变化与对抗 |
| 《谍影重重 2》(The Bourne Supremacy) | 现代非线性记忆叙事 |
| 《指环王 1》 | 史诗结构、序幕建置 |
| 《肖申克的救赎》 | 主题与希望、情节点设计 |
| 《唐人街》(Chinatown) | 经典中间点、悬念结构 |
| 《泰坦尼克号》 | 中间点 (撞冰山) 的能量 |
| 《奔腾年代》(Seabiscuit) | 多人物弧光 |
| 《铁拳男人》(Cinderella Man) | 第三幕长动作段落 |
| 《断背山》 | 第二幕双半结构 |
| 《不结婚的女人》 | 经典情节点 I 案例 |
