## 卡片法的核心理念

> "卡片系统会是你的路线图和向导, 情节点、中间点、次级戏剧性情境脉络, 以及紧要关头 I 和紧要关头 II 是你在途中的校验点。"

### 为什么用卡片?
- **可视化**: 把抽象的故事变成可触摸的物体
- **可重组**: 物理移动比修改文档更轻
- **可校验**: 一眼看清整个故事的节奏
- **可发现**: 重排过程中会冒出新想法

### 卡片 vs. 大纲
| 维度 | 卡片 | 文字大纲 |
|------|-----|--------|
| 修改成本 | 低 (移动) | 高 (重写) |
| 全局视野 | 一目了然 | 必须滚动 |
| 新想法触发 | 高 | 中 |
| 团队协作 | 易 | 难 |

## 整部剧本的卡片分布

菲尔德的标准: 每张卡片 = 一场戏 = 约 2 分钟银幕时间

```
              整部 120 页剧本约 60 张卡片
   ┌─────────────────┬─────────────────────────────┬─────────────────┐
   │  第一幕          │         第二幕              │   第三幕          │
   │  14 张卡片        │       28 张卡片              │   14 张卡片       │
   │  ~ 30 页          │       ~ 60 页               │   ~ 30 页         │
   └─────────────────┴──────────────┬──────────────┴─────────────────┘
                                    14 张
                                    中间点处

   注: 总数浮动 50-70 张均可。第二幕通常拆为前后两组各 14 张。
```

## 第一幕: 14 张卡片

### 为什么是 14?
> "根据我多年的经验, 十四张卡片是最有效的, 这样你就可以用一张卡片写一个场景, 从开篇场景或段落直到第一幕结尾处出现的情节点 I。"

> "如果一个作者正在进行第一幕的结构安排, 而他仅有十三张卡片材料, 那么通常会面临缺乏足够的素材的问题。而当你准备了十五张卡片时, 通常这对第一幕来说又太多了。"

### 14 张卡片的功能分配

| # | 大致页码 | 功能 |
|---|--------|-----|
| 1 | p.1 | **开篇场景** (建立基调、引入主角) |
| 2-3 | pp.2-7 | 建置主角的生活 (职业/个人/私) |
| 4-5 | pp.8-10 | 引介核心配角和情境 |
| 6-7 | pp.11-15 | 主角的"典型一天" (聚焦) |
| 8-9 | pp.16-20 | 第一个小冲突, 暗示问题 |
| 10-11 | pp.21-24 | 问题界定, 主角必须采取行动 |
| 12-13 | pp.25-27 | 推向情节点 I 的关键场景 |
| 14 | pp.27-30 | **情节点 I** (故事真正的开端) |

## 第二幕: 28 张卡片

第二幕通常分为前后两组, 每组 14 张:

### 第二幕前半部分 (14 张, pp.30-60)

| # | 功能 |
|---|-----|
| 1 | 情节点 I 的余波, 主角进入新世界 |
| 2-3 | 探索新情境, 建立"次级戏剧性情境脉络 A" |
| 4-6 | 第一个障碍 (内在/外在) |
| 7-8 | **紧要关头 I (~p.45)** |
| 9-11 | 第二个障碍 + 关系发展 (恋爱/敌对) |
| 12-13 | 推向中间点的关键场景 |
| 14 | **中间点 (~p.60)** (故事转向) |

### 第二幕后半部分 (14 张, pp.60-90)

| # | 功能 |
|---|-----|
| 1 | 中间点的余波, 新情境脉络 B 启动 |
| 2-4 | 第三个障碍 (升级) |
| 5-7 | 关系发生变化, 主角受考验 |
| 8 | **紧要关头 II (~p.75)** |
| 9-11 | 第四个障碍 (最大) |
| 12-13 | 推向情节点 II 的关键场景 |
| 14 | **情节点 II (~p.85-90)** |

## 写卡片的正确方法

### 规则 1: 写得少, 不要写满
> "每张卡片上只写少许的词语, 不必多。很多时候, 我的学生将他们的整个场景写满了卡片的正面和背面, 而在他们着手写电影剧本时, 他们只是将卡片上的东西抄搬到稿纸上。这样出来的东西不会奏效。"

**为什么少**: 留出空间让新想法在写作过程中涌现。卡片是**指南针**, 不是**导航软件**。

### 规则 2: 一张卡片格式

```
┌─────────────────────────────────┐
│  #5                             │
│                                 │
│  迈尔斯和杰克讨论这次旅行         │
│                                 │
│  (主角揭示对葡萄酒的痴迷)        │
│                                 │
│  [冲突: 杰克想泡妞, 迈尔斯想品酒] │
└─────────────────────────────────┘
```

- **卡片编号**: 用于排序
- **场景标题**: 一句话
- **功能注释**: 这场戏要做什么 (可选)
- **冲突线索**: 场景的张力源 (可选)

### 规则 3: 自由联想顺序
> "发生了什么事? 接着会发生什么? 然后又发生了什么? 这些都是具有魔力的词句, 因为它们会在创作过程中不断激发也新的想法和创意。"

按"接下来发生什么"的逻辑铺开, **不要先按时间顺序**——你可能会发现某些事件可以并行或重排。

### 规则 4: 反复修改
完成首轮卡片后:
1. 通读, 找出节奏断裂处
2. 调整词语
3. 重新排序
4. 通读
5. 重复 3-5 次

直到"从一个场景过渡到下一个场景非常顺畅"。

## 卡片的物理操作

### 工具准备
- 3×5 英寸索引卡 (300 张, 不同颜色)
- 一张大桌或地板空间
- 软木板 + 图钉 (用于挂在墙上)
- 数码相机 (拍照保存当前布局)

### 颜色编码 (推荐)
| 颜色 | 用途 |
|------|-----|
| 白色 | 主线场景 |
| 黄色 | 主角的内心戏 |
| 绿色 | 子情节/恋爱线 |
| 红色 | 关键结构点 (情节点、中间点、紧要关头) |
| 蓝色 | 配角的戏 |

### 物理流程
1. **铺地**: 把卡片按当前顺序铺在桌/地上
2. **走动**: 站起来, 从不同角度看
3. **拍照**: 每次重大调整前拍一张
4. **移动**: 物理拖动卡片重排
5. **删除**: 觉得多余的直接拿走 (留出空白也是信号)
6. **添加**: 想到新场景立即写新卡片插入

## 使用案例: 《杯酒人生》第一幕

菲尔德分析《杯酒人生》(Sideways) 第一幕的 14 张卡片:

| # | 卡片 | 戏剧性功能 |
|---|------|----------|
| 1 | 迈尔斯开车去接杰克时迟到了 | 建立主角性格 (心不在焉) |
| 2 | 迈尔斯正在开车 | 时间过渡, 显示焦虑 |
| 3 | 迈尔斯在杰克的未婚妻家里与他会面 | 引介杰克和情境 |
| 4 | 在前往圣巴巴拉的高速公路上 | 旅程开始 |
| 5 | 迈尔斯和杰克讨论他们的这次旅行 | 揭示二人对旅行的不同期待 |
| 6 | 杰克在给未婚妻打电话 | 揭示杰克的婚前焦虑 |
| 7 | 迈尔斯看望母亲 | 揭示主角的家庭背景 |
| 8 | 他们与母亲共进晚餐 | 关系展现 (家庭张力) |
| 9 | 迈尔斯从母亲那里拿钱 | 揭示主角的财务困境 |
| 10 | 迈尔斯和杰克偷偷离开母亲家 | 隐秘的"逃亡" |
| 11 | 杰克的诉求是去泡妞 | 戏剧性需求明确 |
| 12 | 到达圣罗萨村 | 进入故事核心环境 |
| 13 | 迈尔斯给杰克讲授葡萄酒品尝知识 | 主角的"专业自我"显现 |
| 14 | **迈尔斯与玛雅相遇 (情节点 I)** | 故事真正开始 |

**分析**:
- 第 1-6 卡: 建立人物和关系
- 第 7-10 卡: 揭示主角的家庭和困境
- 第 11-13 卡: 进入故事核心环境, 准备情节点
- 第 14 卡: 情节点 I 触发

## 数字时代的卡片

### 推荐工具
- **Scrivener**: 内置卡片视图, 拖拽重排
- **Final Draft**: 内置故事板 (Beat Board)
- **Trello / Notion**: 通用卡片管理
- **iA Writer + 标签**: 极简方案
- **物理卡片**: 仍然是菲尔德的推荐——身体动作激发思维

### 数字 vs. 物理的选择
| 偏好 | 选择 |
|------|-----|
| 喜欢一目了然的全局 | 物理卡片 |
| 频繁修改/远程协作 | 数字工具 |
| 卡在创作瓶颈 | **切换到物理** (变化激发新想法) |

## 何时使用卡片法

### 必须使用
- 第一稿之前的**整体结构设计**
- 第二幕前半部分的**节奏规划**
- 第三幕的**关键场景排序**
- 改写阶段的**结构诊断**

### 可选使用
- 单场景的细化 (一张卡片细分为多张子卡片)
- 子情节的独立规划 (单独一组卡片)
- 多线索叙事的对齐 (并排两行卡片)

### 不必使用
- 临时灵感的捕捉 (用笔记本或手机)
- 对白细化 (这是文档级工作)

## 卡片法的精神

卡片不是装饰品, 是**思维体外化**的工具。

> "故事的进程"应该比"故事的内容"更早被规划。卡片让你**看到**故事在哪里加速、哪里停滞、哪里需要变奏。

当你能用 60 张卡片清晰讲完整部电影时, 你已经准备好写第一稿了。

完成卡片后, 进入对应幕的写作指南: [`act_one.md`](act_one.md) → [`act_two.md`](act_two.md) → [`act_three.md`](act_three.md)。
