# 导演/编剧风格档案师

在创意层与导演分析层之间新增一个**风格决策层**：从用户的主题出发，推荐合适的大师风格，选定后把风格拆解成下游每个技能都能直接消费的维度方案。

产出的《{标题}-风格基因档案.md》属于**导演分析/设计层文档**：不手改、重跑覆盖。风格不满意 → 换候选重跑本技能；下游没表达出风格 → 按档案的下游消费指南改下游，不回头改档案。

---

## 工作流程

```
0.输入检查 → 1.主题解析 → 2.候选推荐 → 3.用户选定 → 4.冲突检查 → 5.生成档案 → 6.保存+下游指引
```

### 第零步：输入检查

必需：主题 / 梗概 / 剧本 / 故事文档（story-creator 产物）任一。
询问（如未提供）：目标平台（Seedance / 海螺 / 万相 / Vidu）、目标片长、题材类型偏好、有没有已经想模仿的人选。

若用户已直接点名（"我要王家卫风格"），跳过第二步的推荐，直接读该人风格卡进入第三步确认借调需求。

### 第一步：主题解析

从输入中提取，作为推荐依据：

| 解析项 | 说明 |
|--------|------|
| 题材类型 | 情感 / 悬疑 / 科幻 / 喜剧 / 现实 / 历史 / 战争 / 动作 / 奇幻 / 治愈 / 青春 |
| 情绪基调 | 压抑、浪漫、荒诞、燃、冷峻、温暖…… |
| 叙事复杂度 | 线性单线 / 多线 / 非线性 / 情绪片段式 |
| 内容占比 | 对话戏、动作戏、静态氛围各占多少 |
| 制作约束 | 目标平台、片长、单镜时长上限 |

### 第二步：候选推荐

1. 读 `references/recommendation-map.md`，按题材/情绪反查候选池
2. 到对应名册文件（directors-cn / directors-intl / screenwriters）**只读候选人的风格卡**（文件较长，用 grep 按人名定位）
3. 剔除或警示"避开主题"命中用户主题的候选
4. 输出推荐表，3-5 位候选：

```markdown
| 候选 | 一句话理由 | 参照作品感 | AI还原度 | 风险/取舍 |
```

推荐原则：

- **AI 还原度优先**：总还原度 C 的候选必须附降级预案才能进推荐表
- **平台适配**：结合目标平台特性（Seedance 叙事强 / 万相美学表达 / Vidu 适合短镜头 / 海螺时间序列运镜）
- **不止推"最像"的**：至少 1 位安全牌 + 1 位惊喜牌（跨题材反差用法，注明为什么可能成立）
- **主动提示借调组合**：如"主风格贾樟柯 + 借调索金对话密度"这类有价值的混搭，在推荐表后列 1-2 组

### 第三步：用户选定

用户确定：主风格一位 + 可选借调（维度 ← 人名）。

### 第四步：冲突检查（有借调时必做）

按 `references/style-card-format.md` 的混搭规则逐项检查借调维度与主风格是否顶撞（如：高密度连珠对话 vs 主风格的凝滞留白节奏）。有冲突则给出裁决方案（谁让步、在哪些场景让步），写进档案第 4 节。

**硬性混搭规则**：

- 主风格默认占据全部 8 个维度
- 借调最多 2 个维度，每个维度只能来自一位
- **视觉类维度（色彩·光影 + 构图·运镜）必须同源，不可拆借**——保护视觉整体性
- 可借调维度仅限：叙事结构、对话·台词、剪辑节奏、动作·场面

### 第五步：生成风格基因档案

按 `references/style-card-format.md` 第三部分的档案模板生成。核心要求：**不照抄风格卡**，把每个维度实例化成"本片怎么做"——通用手法 → 落到本片的具体场景、具体镜头策略、具体提示词资产。

### 第六步：保存与下游指引

保存为 `{标题}-风格基因档案.md`，然后告知用户后续用法：

> 之后调用 storyboard-blueprint、visual-director、shot-rhythm-planner、scene-atmosphere、dialogue-scene-director、action-scene-choreographer、平台分镜技能、reference-image-prompt-polisher、storyboard-reviewer 时，把这份档案一并提供，各技能会自动沿用对应维度。

---

## 与下游的优先级约定

- 档案覆盖下游技能的**默认审美偏好**（如 visual-director 的配色直觉、shot-rhythm-planner 的节奏模板选择）
- 档案**不覆盖专业硬规则**（轴线、越轴、观众可懂性、信息投放底线）——冲突时专业规则优先，下游技能会在产物中标注冲突点
- 下游产物开头统一标注：`已沿用风格：{主风格}（借调：{维度}←{人名}）`
