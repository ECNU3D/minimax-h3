### 张艺谋（Zhang Yimou）

**类别**：华语导演 ｜ **总还原度**：S
**风格签名**：单色统治的民俗史诗——一种颜色淹没画面、万人阵列成图案、执念驱动的寓言
**适配主题**：民俗乡土、历史史诗、仪式与庆典、色彩浓烈的寓言故事、大场面群像、国风视觉短片
**避开**：都市轻喜剧、日常生活流、需要细腻现代感的题材、多线复杂叙事

| 维度 | 风格要点 | AI还原度 |
|------|---------|---------|
| 叙事结构 | 线性寓言：故事骨架极简，一个执念驱动全片（告状、复仇、等一个人）；开场直接给出执念，结尾以仪式或轮回收束；信息靠画面符号而非台词交代 | A |
| 色彩·光影 | 单一主色统治整场（红绸红、染坊黄、靛蓝），占画面70%以上；高饱和；自然光+逆光中的漂浮尘埃；每换一幕换一种主色 | S |
| 构图·运镜 | 极端中轴对称、大远景人海几何阵列、大俯拍把人群拍成图案；单人时用顶天立地的正面特写 | S |
| 剪辑节奏 | 仪式段落慢切、镜头停留展示奇观；动作段落跟鼓点快切；段落间用色彩突变转场 | A |
| 对话·台词 | 台词少而直白、乡音土话、重复喊话式宣言（同一句话在片中喊三遍以上）；不写机锋，写执念 | A |
| 动作·场面 | 群体动作整齐划一（颠轿、捶布、擂鼓）、漫天箭雨、红绸飞舞；个体动作弱、群像奇观强；整齐度靠提示词强调"整齐划一、同步" | A |
| 声音·音乐 | 唢呐、大鼓、人声呐喊合唱；仪式段落音乐推满，日常段落只留环境声；音效跟随群体动作打点 | A |
| 表演风格 | 外放浓烈、执念写在脸上；标志是倔强的正面凝视特写；哭喊不遮掩 | B |

**标志性手法 Top 5**：
1. 单色统治：一场戏只允许一种主色占据80%画面（漫山红绸/染坊黄布/满堂红灯笼），人物服装同色系或以黑衣反衬
2. 万人几何阵列大俯拍：人群排成方阵、环形或字形图案，大俯角或航拍机位，动作整齐划一
3. 逆光尘埃与漫天箭雨：强逆光中漂浮的尘埃颗粒、遮天蔽日的箭矢群从天而降，制造史诗颗粒感
4. 仪式化群体劳动：颠轿、捶布、酿酒、擂鼓等动作节奏化重复，镜头跟着节奏切
5. 色彩突变转场：上一幕结束于主色A的满画幅，下一幕以主色B的满画幅开场，用颜色宣告章节更替
**提示词关键词包**：`大红灯笼、高饱和单色主导、万人阵列大俯拍、中轴对称构图、逆光尘埃颗粒、漫天箭雨、红绸飞舞、黄土高坡、唢呐锣鼓、仪式化群体动作、染坊黄布垂落、倔强正面凝视特写`

### 陈凯歌（Chen Kaige）

**类别**：华语导演 ｜ **总还原度**：A
**风格签名**：文人史诗与戏梦人生——大时代碾过个人、戏台与命运互文、华美与悲怆同框
**适配主题**：历史跨度叙事、戏曲与传统艺术题材、盛唐幻境、命运悲剧、文化怀旧、人物传记式短片
**避开**：轻快日常、快节奏爽片、极简写实、市井喜剧

| 维度 | 风格要点 | AI还原度 |
|------|---------|---------|
| 叙事结构 | 编年史大跨度、章节化推进；人物命运绑定时代事件（一段字幕/一个符号宣告年代）；戏中戏与现实互文：台上唱的就是台下的命 | B |
| 色彩·光影 | 金碧辉煌与深沉暗部并存；烛光、灯笼、火光的暖调主光；幻境段落用幻彩光斑与悬浮物；暗部藏细节不死黑 | S |
| 构图·运镜 | 舞台式正面构图、大景深纵深调度（长廊、大殿一眼望穿）；缓推缓拉逼近人物；仰拍庙堂建筑压迫感 | A |
| 剪辑节奏 | 从容段落式，一场戏讲透再走；高潮跟戏曲锣鼓点切；年代跳跃用同机位叠化 | A |
| 对话·台词 | 文雅书面化、命运感宣言（"不疯魔不成活"式金句）；潜台词重，说戏即说人 | A |
| 动作·场面 | 大场面重美术陈设而非打斗：仪典、盛宴、戏台开锣；千人朝拜式的场面靠布景与阵列 | A |
| 声音·音乐 | 京胡、锣鼓点、戏腔吊嗓与交响乐并置；重要时刻用戏曲唱段替代台词 | A |
| 表演风格 | 浓烈舞台化、眼神戏为主；扮相与身段本身即表演；情绪到顶点用一个定格般的亮相 | B |

**标志性手法 Top 5**：
1. 戏中戏互文剪辑：戏台上的唱段画面与台下人物的真实命运交叉剪辑，唱词即判词
2. 烛光大殿纵深镜头：成排烛台/灯笼延伸向纵深，人物从深处缓缓走来，镜头缓慢后拉
3. 盛景幻境：极乐之宴式画面——悬浮花瓣、幻彩光斑、酒池灯影，饱和度拉满的人造仙境
4. 命运慢推特写：在人物听到判决性消息的瞬间，镜头极缓推向面部，背景虚化只剩一张脸
5. 同机位跨年代叠化：同一场景同一机位，人物妆发与陈设变化，一次叠化跨过十年
**提示词关键词包**：`金碧辉煌大殿、烛光灯笼暖调、戏台戏中戏、京剧扮相、长廊纵深调度、缓慢推镜特写、盛唐幻境、悬浮花瓣光斑、命运悲怆氛围、同机位年代叠化、锣鼓戏腔、雕梁画栋`

### 姜文（Jiang Wen）

**类别**：华语导演 ｜ **总还原度**：A
**风格签名**：荷尔蒙魔幻现实——阳光过曝的记忆、机关枪台词、站着把事办成的狂气
**适配主题**：革命浪漫、少年记忆、荒诞寓言、雄性对峙、黑色幽默、热血宣言式短片
**避开**：温吞文艺、慢节奏静观、小清新、需要克制收敛的题材

| 维度 | 风格要点 | AI还原度 |
|------|---------|---------|
| 叙事结构 | 强主观视角、记忆不可靠（旁白自己承认记错了）；事件密集推进不停顿；开场即高能，结尾常升格成寓言 | A |
| 色彩·光影 | 金黄过曝的正午阳光、高光打爆、暖调怀旧；屋顶、白墙、麦田等强反光场景；夜戏用火光和灯泡直射 | S |
| 构图·运镜 | 低角度仰拍英雄机位（人物顶着天空走来）、快速推轨逼近、环绕对峙双方旋转 | A |
| 剪辑节奏 | 极快，对白正反打密集如乒乓；动作一步到位不拖泥带水；配乐推满时剪辑跟着音乐冲 | A |
| 对话·台词 | 机关枪式高速对白、重复排比、荒诞逻辑辩论绕圈；台词文本可执行，但高语速表演与口型同步依赖抽卡 | B |
| 动作·场面 | 暴力干脆、一击毙命式处理；枪战仪式化（列队、齐射）；奔跑戏多且必须带风 | A |
| 声音·音乐 | 宏大交响乐怼着荒诞场面放（庄严配乐×不正经画面的反差）；音乐一响就推到底不收 | A |
| 表演风格 | 亢奋外放、荷尔蒙外溢；大笑、咆哮、大步流星；情绪从不低于八分 | B |

**标志性手法 Top 5**：
1. 金黄过曝逆光：正午强光打爆高光边缘，少年在屋顶/铁轨上奔跑，画面整体泛金
2. 仰拍英雄机位：机位贴地仰拍，人物大步走来顶着一整片天空，衣摆带风
3. 宏大配乐×荒诞动作反差：庄严交响乐全程推满，画面里的人在干一件不着调的事
4. 环绕对峙：两人对峙时镜头绕轴环绕旋转，语速与转速同步加快
5. 蒸汽与飞驰意象：火车喷着白汽冲来、自行车从坡顶俯冲，速度感物件承载情绪爆发
**提示词关键词包**：`金黄过曝阳光、正午屋顶奔跑、仰拍英雄机位、逆光剪影、宏大交响配乐、快速推轨、蒸汽火车冲来、环绕对峙旋转、军绿怀旧色调、大笑特写、烈日白墙、自行车俯冲`

### 王家卫（Wong Kar-wai）

**类别**：华语导演 ｜ **总还原度**：S
**风格签名**：都市暧昧情绪流——霓虹迷离的夜、抽帧慢门的时间、独白里的错过
**适配主题**：都市孤独、暗恋与错过、深夜城市、怀旧（90年代/千禧感）、情绪片段式短片、失眠与漫游
**避开**：强情节叙事、需要高密度信息交代的题材、阳光正剧、动作爽片

| 维度 | 风格要点 | AI还原度 |
|------|---------|---------|
| 叙事结构 | 碎片化、非线性；旁白独白承担主叙事；用编号、日期、期限具体化情绪（"一万年""5月1日过期"）；结尾开放不闭合 | A |
| 色彩·光影 | 高饱和霓虹撞色（红绿为主）、钨丝灯暖黄、雨夜湿面反光、大面积暗部只留局部亮斑 | S |
| 构图·运镜 | 手持贴身跟拍、前景遮挡（门框/玻璃/珠帘/雨幕）、镜像与倒影构图、人物常偏置于画面边缘 | S |
| 剪辑节奏 | 抽帧慢门（step-printing）：主体拖影、背景人流加速；瞬间加速与大段凝滞交替；跳切 | A |
| 对话·台词 | 独白远多于对白；不直说情感，用数字和物件寄情（凤梨罐头、过期机票）；对白短、留白长 | S |
| 动作·场面 | 弱项；偶有的打斗也做成抽帧模糊的情绪化处理，不求招式清晰 | A |
| 声音·音乐 | 老歌循环（拉丁、爵士、粤语老歌）、单曲反复出现成为情绪锚、环境底噪（雨声、电车） | A |
| 表演风格 | 克制、慵懒、目光游离不对视；情绪藏在抽烟/吃东西/整理衣物等小动作里 | B |

**标志性手法 Top 5**：
1. 抽帧慢门：人物动作拖影凝滞、背景人流车流加速虚化——用于"世界很快、我很慢"的孤独时刻
2. 前景遮挡偷窥机位：隔着门框/珠帘/玻璃拍人物，观众成为窥视者
3. 独白+空镜组合：画外音说心事，画面给城市空镜或人物背影
4. 数字与物件寄情：把抽象情感兑换成具体数字/物品，台词只说物不说情
5. 单曲循环成情绪锚：同一首老歌在不同场景反复出现，每次含义加深
**提示词关键词包**：`霓虹红绿撞色、雨夜街头湿面反光、钨丝灯暖黄、手持贴身跟拍、前景门框遮挡、玻璃倒影、抽帧慢门拖影、背景人流加速、香烟烟雾缭绕、90年代港风、狭窄楼道、老式电扇`

### 杜琪峰（Johnnie To）

**类别**：华语导演 ｜ **总还原度**：A
**风格签名**：宿命站位美学——黑暗中雕塑般的枪手群像、静止对峙、命运一触即发
**适配主题**：黑帮宿命、警匪对峙、夜战、兄弟情义、都市犯罪、冷峻群像短片
**避开**：明亮温情、儿童家庭向、田园牧歌、需要热闹喜庆氛围的题材

| 维度 | 风格要点 | AI还原度 |
|------|---------|---------|
| 叙事结构 | 多方博弈棋局式：每一方出一步，局势翻转靠站位与眼神而非台词交代；开场先摆棋盘（各方亮相），结尾宿命闭合 | A |
| 色彩·光影 | 低照度夜色、冷蓝为底+局部暖光源（路灯、烟头、车灯）；硬光勾轮廓、人物半张脸在暗部；烟雾中光束成型 | S |
| 构图·运镜 | 群像几何站位（三角、环形、一字排开），人物如雕塑静止；机位固定或极缓横移扫过各人面孔；大空间（广场、商场）孤立小人物 | S |
| 剪辑节奏 | 长时间静止蓄势（只有烟雾和衣角在动）→枪火爆发瞬间快切；爆发后立刻回归静止 | A |
| 对话·台词 | 极简，大段沉默；一句话定生死；信息靠动作交代（递烟、推枪、点头） | A |
| 动作·场面 | 站定式枪战：人物几乎不跑动，靠精确站位与掩体几何关系推进；弹道与走位的精确编排依赖多次抽卡 | B |
| 声音·音乐 | 口哨、吉他小调式主题反复；枪声在长久静默后炸响；环境声压到极低衬托爆发 | A |
| 表演风格 | 面无表情、动作极省（抽烟、整理西装）；眼神横移代替转头；狠话平静地说 | B |

**标志性手法 Top 5**：
1. 雕塑式群像站位：多名持枪人物在黑暗中呈三角形或环形静止站位对峙，只有烟雾在飘
2. 烟雾光束：手电、车灯或路灯光束切开浓烟，人物剪影立于光束边缘
3. 静止蓄势后爆发：全员静止数秒（画面近乎定格），然后枪口火光在一秒内连续爆闪
4. 缓慢横移扫脸：镜头以恒定慢速横移，依次扫过对峙各方的面孔与持枪的手
5. 空旷夜景孤立构图：深夜广场/商场/停车场的大远景，几个小小的人影分立两端
**提示词关键词包**：`低照度冷蓝夜色、烟雾中光束、三角站位群像、静止持枪对峙、缓慢横移扫过面孔、硬光轮廓剪影、空旷广场夜景、风衣剪影、枪口火光爆闪、香烟红点明灭、宿命感黑色氛围、湿冷街道反光`

### 徐克（Tsui Hark）

**类别**：华语导演 ｜ **总还原度**：A
**风格签名**：武侠狂想奇观——飞檐走壁的凌厉剪辑、剑气纵横的江湖、正邪难辨的妖气
**适配主题**：武侠江湖、奇幻怪谈、飞天动作、客栈夜戏、快节奏冒险、国风奇观短片
**避开**：写实日常、慢节奏文艺、现代都市写实、需要克制表演的心理剧

| 维度 | 风格要点 | AI还原度 |
|------|---------|---------|
| 叙事结构 | 开场即事件（三分钟内必见血或见宝）；强情节快推进，悬念钩子一个接一个；人物亮相必带标志性动作或道具 | A |
| 色彩·光影 | 高对比戏剧光：冷月蓝夜戏+火把烛光橙的冷暖对撞；妖异场景加青绿幻光；白衣、红衣在暗景中跳出 | S |
| 构图·运镜 | 大幅度吊威亚式运动镜头（跟着人物腾空、俯冲）、倾斜构图制造不安、快速变焦冲向面部 | A |
| 剪辑节奏 | 凌厉快切，一招动作拆成三四个角度碎切；文戏也不停留，语毕即切 | A |
| 对话·台词 | 江湖腔：豪气宣言+俏皮斗嘴；语速快、你来我往；人物用绰号和名号自报家门 | A |
| 动作·场面 | 飞天遁地、一人对百人、剑气掀翻屋瓦；动作夸张但招式意图清晰（劈、扫、点、封）；长串连招的连贯性需抽卡 | A |
| 声音·音乐 | 豪迈主题曲（笛、琵琶+电子鼓混搭）、刀剑破空声与衣袂猎猎声放大处理 | A |
| 表演风格 | 戏剧化、眉目传情、亦正亦邪的笑；女侠英气、反派妖冶，造型即人物 | B |
