# 风格卡格式与风格基因档案模板

目录：一、AI 还原度评级定义 ｜ 二、风格卡 Schema ｜ 三、风格基因档案模板 ｜ 四、借调冲突检查清单

---

## 一、AI 还原度评级定义

评估"当前 AI 视频生成平台（Seedance / 海螺 / 万相 / Vidu）能把这条风格特征还原到什么程度"，全库统一：

| 评级 | 含义 |
|------|------|
| S | 一次生成即可稳定还原（多为静态视觉特征：色彩、光影、构图、氛围） |
| A | 需提示词精调可还原（多为运镜、节奏、简单调度） |
| B | 多次抽卡碰运气（复杂调度、长镜头、精确表演） |
| C | 当前平台基本做不到（超长镜头静观、精确微表情、复杂群戏走位）——选它必须给降级替代方案 |

每张卡最后给一个**总还原度**（取各维度加权印象分，视觉维度权重最高），供推荐环节快速筛选。

## 二、风格卡 Schema

每张风格卡按以下结构撰写（完整示例见 `directors-cn.md` 的王家卫条目）：

```markdown
### 姓名（外文名/常用译名）

**类别**：华语导演 / 国际导演 / 编剧 ｜ **总还原度**：S/A/B/C
**风格签名**：一句话抓住风格本质
**适配主题**：适合的题材、情绪、场景类型（推荐环节的主要匹配依据）
**避开**：不适合的题材——命中用户主题时剔除或警示

| 维度 | 风格要点 | AI还原度 |
|------|---------|---------|
| 叙事结构 | 信息投放习惯、线性/非线性、开场方式、结尾习惯 | |
| 色彩·光影 | 色板、饱和度、光源习惯、明暗对比 | |
| 构图·运镜 | 景别偏好、镜头运动习惯、机位特征 | |
| 剪辑节奏 | 镜头长短、张弛习惯、转场特征 | |
| 对话·台词 | 密度、腔调、独白/对白比例、潜台词习惯 | |
| 动作·场面 | 动作戏/大场面处理方式（不适用标"—"） | |
| 声音·音乐 | 配乐倾向、环境音、静默使用 | |
| 表演风格 | 表演幅度、面孔选择、情绪外露程度 | |

**标志性手法 Top 5**：五条具体到可直接写进 prompt 的手法（不是"擅长氛围营造"这种空话，而是"抽帧慢门：主体动作拖影、背景人流加速虚化"这种可执行描述）
**提示词关键词包**：`中文关键词、逗号分隔、可直接拼进平台分镜或生图提示词`
```

撰写纪律：

- 每个维度写**可执行的具体特征**，禁止影评式空话（"极具个人风格""大师手笔"一律不要）
- 风格要点里优先写"AI 生成时怎么用"视角的描述
- 编剧类风格卡：色彩·光影、构图·运镜两个维度标"—"；重点写足叙事结构、对话·台词、表演风格三个维度，另加一行 **人物塑造** 维度替代"动作·场面"
- 关键词包全部用中文（生成平台对中文提示词响应更稳），8-15 个词组

## 三、风格基因档案模板

输出文件名：`{标题}-风格基因档案.md`。共 8 节，逐节要求：

```markdown
# {标题}-风格基因档案

> 本档案由 auteur-style-profiler 生成，属导演分析/设计层文档：不手改，重跑覆盖。
> 已选定风格：{主风格}（借调：{维度}←{人名}，无借调则写"无"）

## 1. 风格决策记录
主风格、借调项、当时的候选表、各候选落选原因（一句话即可）。重跑时这一节保证决策可追溯。

## 2. 风格签名与本片定调
一段话：这部片在选定风格下"看起来/听起来/感觉起来"是什么样。写给所有下游技能的总纲。

## 3. 逐维度落地方案
8 个维度逐一写成表格：

| 维度 | 来源 | 通用手法 | 本片具体做法 |
|------|------|---------|-------------|

"本片具体做法"必须落到本片的具体场景/角色/情节，不许照抄风格卡原文。
每行标注主要消费者：叙事结构→storyboard-blueprint；色彩·光影→visual-director/scene-atmosphere；
构图·运镜→continuity-blocking-planner/平台分镜；剪辑节奏→shot-rhythm-planner；
对话·台词→dialogue-scene-director；动作·场面→action-scene-choreographer；
声音·音乐→平台分镜/release-gate装配规范；表演风格→对话/动作戏技能。

## 4. 借调冲突检查表（无借调时写"无借调"）
| 冲突点 | 主风格立场 | 借调方立场 | 裁决 |

## 5. 标志性手法植入点
从主风格手法 Top 5 中选 3-5 条，落到本片具体场景："第X场用{手法}，因为{叙事理由}"。
有叙事理由才植入，不为炫技而植入。

## 6. 提示词资产包
- 全局画风前缀增强：一段可拼接到每镜提示词开头的风格描述（供 visual-director 的画风前缀融合）
- 氛围词库 / 运镜词库：按本片场景分组
- 负面清单：本风格下**不该出现**的元素（如王家卫风格下的"明亮均匀布光、大广角航拍"）——供平台分镜写排除项

## 7. 下游消费指南
| 下游技能 | 读哪几节 | 怎么用 |
逐技能一行，明确引用方式。

## 8. AI 还原度风险与降级预案
本片用到的 B/C 级特征逐条列出：风险描述 + 降级替代（如"长镜头静观→改为同机位3连镜，剪辑上保持凝滞感"）。
```

## 四、借调冲突检查清单

有借调时逐项过（结果写入档案第 4 节）：

1. **节奏对撞**：借调方的语速/剪辑密度 vs 主风格的节奏习惯——谁让步？在哪类场景让步？
2. **情绪温度**：借调方的情绪外露程度 vs 主风格的克制程度是否矛盾？
3. **信息投放**：借调叙事结构时，主风格的视觉留白是否还有空间承载？
4. **腔调违和**：借调对话风格时，台词腔调放进主风格的画面里是否出戏？
5. **平台可行性**：混搭后的组合是否产生新的 C 级还原风险？

任何一项冲突无法裁决 → 建议用户放弃该借调，回单一主风格。
