# 中文字幕排版与验收

本项目 1344×768 横片默认：36px 中文字体、左右留 8%、文字实际下边缘留 9%、最多两行、每行先按 22 字上限拆分。它们是起始样式，不是平台强制标准；保留用户指定的画幅和风格。

## 字幕制作

1. 从已生成 voice master 的准确 transcript 出发；先测原音频，再把分句时间转换到剪辑后的全片时间。ASR 仅作对齐候选，姓名/数字手动比对。
2. 依据语义分句，一屏一个意群，尽量单行，最多两行。禁止整段旁白一行铺满，也不通过缩成小字掩盖溢出。保留原话，不擅自改台词。
3. 输入格式及调用见 [剪辑规范](../../docs/video-editing-workflow.md)。调用固定 `scripts/caption_layout.py` 生成透明 PNG 和测量报告；它检查位置和长度，不伪装成语音对齐器。
4. 未做音频对齐时 `alignment_status=unverified`。按字符均分时间最多是草稿，不得称“自动对齐验收通过”。跨镜保留连续全局 cue，避免字幕闪断或整段重显。
5. 明确传中文字体，不可 fallback 到缺中文字形的字体。以 `textbbox` 和最终 alpha bbox 检查，不用 `y=700` 当文字底边。

## 遮挡与复核

- 在实际帧上标注脸、手、道具文字的保护矩形；与字幕冲突时先拆短句，再考虑整句移到顶部，不逐帧乱跳。
- 以完整画幅检查最长句、双行、字幕第一/最后一帧、剪点前后各一帧。另缩小到手机观看尺寸看是否可读。
- 字幕 burn-in 应在裁切/缩放后完成；改变画幅后重新检查。黑边、平台按钮区按目标平台另设，不能默认套用横片 9%。
- 检查 JSON 的时段排序/重叠/超时长、字符/秒；异常值提示人工审查，不静默删字、挪对白或拉伸画面。

输出字幕源、样式、PNG/ASS/SRT（按需要）、layout-report、抽帧证据。技术布局通过、实听同步通过、用户审片三个状态分开。
