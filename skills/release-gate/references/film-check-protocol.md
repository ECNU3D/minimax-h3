# 成片体检协议（模式 C）

> 以下 ffmpeg/ffprobe 命令已在本机（macOS + Homebrew ffmpeg）实测可用。
> 体检对象必须是**最终导出的成片文件**，不是剪辑工程预览。

## 第一部分：技术体检

### 1. 基本信息

```bash
ffprobe -v error -show_entries format=duration -of csv=p=0 成片.mp4          # 时长（秒）
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,r_frame_rate -of csv=p=0 成片.mp4
```

### 2. 全片语音频段响度扫描（找可疑静默段）

15 秒一个窗口，测语音频段（200Hz-4kHz）mean_volume：

```bash
D=$(ffprobe -v error -show_entries format=duration -of csv=p=0 成片.mp4 | cut -d. -f1)
for ((s=0; s<D; s+=15)); do
  v=$(ffmpeg -hide_banner -nostats -ss $s -t 15 -i 成片.mp4 \
      -af "highpass=f=200,lowpass=f=4000,volumedetect" -f null - 2>&1 \
      | grep mean_volume | grep -oE '\-?[0-9]+\.[0-9]+')
  echo "$s-$((s+15))s: ${v}dB"
done
```

输出整理成响度曲线表。**判读标准**（源自《好》取证实测）：

| 语音频段 mean_volume | 判读 |
|----------------------|------|
| -17 ～ -25dB | 正常对白区间 |
| -25 ～ -35dB | 黄灯：若该窗口应有台词，逐条静听确认 |
| < -35dB | 红灯：该窗口若在必听台词清单内 = 事故（《好》事故段实测 -38～-46dB） |

### 3. 必听台词逐条验收（体检核心）

对装配规范"必听台词清单"的每一条：

1. 在成片中定位其实际时间窗（重剪后位置会变，以实听定位为准）；
2. 静听：能否不看字幕听清全文；
3. 测量该窗口：

```bash
ffmpeg -hide_banner -nostats -ss {起} -t {长} -i 成片.mp4 \
  -af "highpass=f=200,lowpass=f=4000,volumedetect" -f null - 2>&1 | grep -E "mean_volume|max_volume"
```

4. 判定：与全片对白均值偏差 >6dB 或绝对值 <-35dB → **不可听，触发否决线**。

### 4. 字幕完整性 + 禁删项 + 乱码扫描

抽帧（每 2 秒一帧，兼作盲审素材）：

```bash
mkdir -p frames && ffmpeg -v error -i 成片.mp4 -vf fps=0.5 frames/%04d.jpg
```

- 对照装配规范字幕清单：每条字幕在预期时间的帧里**在场且文本正确**；
- 禁删清单逐项确认（重点：片尾卡——上一版《好》的真实故事卡被剪成"谢谢观看"）；
- 浏览全部帧，标记乱码/伪汉字（特写乱码=否决线）。

## 第二部分：试映盲审

模拟"零背景观众第一遍观看"。执行者必须是新会话 agent 或未接触项目的真人；创作者自审只能作参考并标注可信度降级。

1. **素材准备**：抽帧序列（上一步的 frames/）+ **实听台词转写**——逐段真实听写成片里实际可辨的台词与字幕。**禁止用剧本文本代替**：剧本里有 ≠ 成片里听得见，上次的混音事故正是这样漏掉的。响度扫描中 <-35dB 窗口的台词一律不进转写（观众听不见）。
2. **全信号复述**：给帧+转写，要求从头到尾复述故事（谁、发生了什么、为什么、结局）。
3. **静音复述**：只给帧，再复述一遍主线因果。
4. **判定**：对照观众认知时间线（或临时提取的枢纽信息清单）逐条打分：送达 / 缺失 / 误解。任何一条枢纽信息缺失或误解 → 触发否决线。

## 第三部分：报告与裁决

`{标题}-成片体检报告.md` 结构：

1. 基本信息 + 体检模式（完整 / 降级[无装配规范，临时清单来源]）
2. 响度曲线表 + 可疑段清单
3. 必听台词逐条验收表（定位窗口 / 实测dB / 与均值差 / 可听判定）
4. 字幕清单核对表、禁删项核对表、乱码清单
5. 盲审记录（执行方式 / 全信号复述原文 / 静音复述原文 / 枢纽信息逐条判定）
6. **裁决**：✅ 可发布 / ❌ 修复后复检（列出触发的否决线与修复指令）

**否决线（任一触发即 ❌，禁止"基本没问题/瑕不掩瑜"）**：

1. 任何必听台词不可听
2. 盲审复述在枢纽信息处断裂或误解
3. 禁删项缺失
4. 特写乱码文字
5. 字幕清单缺漏 ≥2 条

修复后**重跑受影响的检查项 + 完整盲审**，产出复检报告（复述测试不得复用第一轮结果）。
