# 素材验收规则（模式 B）

生成的片段 ≠ 提示词写的画面。验收在剪辑之前，重生成的成本远低于成片返工。

## 准备

1. 片段按分镜号命名放同一文件夹（如 `clips/镜01.mp4`）。
2. 手边打开分镜脚本（📌信息增量申报）与装配规范。
3. 批量抽帧（每条片段取首/中/尾三帧）：

```bash
mkdir -p frames
for f in clips/*.mp4; do
  n=$(basename "$f" .mp4)
  d=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$f")
  ffmpeg -v error -ss 0 -i "$f" -frames:v 1 -y "frames/${n}-a首.jpg"
  ffmpeg -v error -ss $(echo "$d/2" | bc -l) -i "$f" -frames:v 1 -y "frames/${n}-b中.jpg"
  ffmpeg -v error -sseof -0.5 -i "$f" -frames:v 1 -y "frames/${n}-c尾.jpg"
done
```

4. **每一条**片段都听音轨（不只是有台词的）——🅐 镜听台词对不对，🅑 镜听有没有本不该存在的人声。粗筛可先测语音频段响度：

```bash
ffmpeg -hide_banner -nostats -i clips/镜07.mp4 \
  -af "highpass=f=200,lowpass=f=4000,volumedetect" -f null - 2>&1 | grep mean_volume
```

## 六查（逐条片段执行）

对照装配规范的**音轨归属表**确认本镜属 🅐（模型生成人声）还是 🅑（后期录制）后再查 2、3。

| # | 查什么 | 不合格判定 |
|---|--------|-----------|
| 1 | **信息可见**：📌申报的信息增量在画面里真的发生了吗 | 枢纽事件不可见（白光/黑幕/只有反应镜）；申报的动作没渲染出来 |
| 2 | **台词可听可辨**（🅐 镜）：内容正确、吐字可辨、口型对得上 | AI 吞字/改词/含糊到需要猜；口型与台词不同步；语音频段 mean_volume < -35dB |
| 3 | **误生成人声**（🅑 镜）：音轨里不该有任何人声 | 听到模型自己配的台词、旁白或嘟囔 → **直接重生成**。不接受"后期静音音轨"降级：模型配音会连带生成口型、说话表演与错误的动作节奏，画面已被污染 |
| 4 | **文字乱码**：画面内所有文字 | 特写乱码直接不合格；远景乱码标记后期处理 |
| 5 | **一致性**：角色脸型/服装/道具/场景 vs 参考图与相邻镜 | 观众会认成另一个人/另一个地方的程度 |
| 6 | **衔接**：与上一镜尾帧的空间、光线、道具状态 | 越轴、光线跳变、道具消失/易位且无剧情理由 |

## 判定与处置

| 判定 | 含义 | 必须附带 |
|------|------|----------|
| ✅ 合格 | 六查全过 | — |
| 🔁 重生成 | 查1/2/3 失败，或查4 特写级失败 | 具体修法：提示词改哪一段文本 / 换哪张首帧 / 改用首尾帧入口 |
| ⚠️ 降级使用 | 部分可用 | 可用秒段 + 后期补救方式（叠字/裁切/借帧） |

## 报告结构（`{标题}-素材验收报告.md`）

1. 汇总表：总数 / 合格 / 重生成 / 降级，重生成清单置顶
2. 逐条明细：镜号 | 🅐/🅑 | 六查结果 | 判定 | 处置指令
3. 跨镜一致性问题单独列（涉及多条片段的角色漂移等）

## 失败情形

- 只看首帧截图不听音轨
- 只听"有台词的镜"，跳过 🅑 镜的误生成人声检查
- 🅑 镜听到模型配音却判"降级使用（后期静音）"
- 一致性只对照参考图、不对照相邻镜
- 判"重生成"却不给具体修法
- 为省生成成本把特写乱码/枢纽不可见判成"降级使用"
