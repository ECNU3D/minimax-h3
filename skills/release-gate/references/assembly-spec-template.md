## 2. 必听台词清单（混音验收对象，一条不可失）

| # | 镜号 | 台词全文 | 挂靠信息 | 为什么不可失 | 响度要求 |
|---|------|----------|----------|--------------|----------|
| 1 | | | I_ / 拍点 | （如：全片唯一名字焊点） | 语音频段 mean_volume 与全片对白均值差 ≤6dB |

- 全片对白响度目标：语音频段（200Hz-4kHz）mean_volume **-17 ～ -25dB**
- 提取规则：观众认知时间线里每条**枢纽信息**的台词通道送达点、每个**独立拍点**的台词，全部入列

## 3. 音轨归属表（全片每一句人声都要盖章）

规则见 `../../narrative-info-planner/references/audio-lane-rules.md`。

| # | 镜号 | 台词全文 | 🅐模型生成／🅑后期录制 | 时间窗 | 字数·语速·预算 | 提示词正文核对 |
|---|------|----------|------------------------|--------|----------------|----------------|
| 1 | | | | | 11字+1破折号@3.3字/秒=4.0秒 ✅ | 正文无台词原文，已写"无人声、无画外配音" ✅ |

- **必听台词清单里的每一条默认都是 🅑**（要精确入点与响度），除非它是画面内人物开口且已确认模型口型可用。
- **🅑 的句子，原文不得出现在任何提示词正文里**。定稿前回分镜脚本逐个代码块 grep `"` `“` `旁白` `广播` `画外音` `配音` `独白`，命中即打回改分镜——不是"剪辑时静音就行"。
- **每句都要算预算**：`可容纳字数 ≈ (窗口秒数 − 0.4) × 语速`（快对白 5／正常对白 4.5／广告旁白 4／失真广播·强调句 3–3.5 字每秒；破折号省略号每处扣 0.3 秒、逗号扣 0.15 秒）。窗口 < 预算的，**在这一步**决定砍字／跨镜／换字幕，不留给配音演员"念快点"。
- 跨镜的句子在"时间窗"列写明跨镜区间与 J-cut，并确认下一镜提示词同样不含台词原文。
