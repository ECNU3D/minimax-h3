# 发布闸门（装配规范 · 素材验收 · 成片体检）

## 本仓库执行补充（2026-09-16）

- 模式 B 的“重生成”是验收建议，不是无限提交授权。本地 H3 只能通过 `scripts/h3_batch.py`，遵守 `docs/h3-agent-production.md` 的两次提交预算和 STOP 终态；预算耗尽时报告失败并退出 goal。
- 模式 C 的字幕核对增加 `skills/subtitle-layout-qa/SKILL.md` 和固定工具 `scripts/caption_layout.py`：实际字形边界、溢出、最多两行、安全区、最长句与跨镜抽帧。字幕在场不代表文字完整可读。
- 必要音轨缺失时构建必须失败；不能沿用历史脚本“跳过缺失文件”后只报响度通过。真实语音对齐、视觉布局、听音和用户接受分别记录，未实听不得声称声音合格。
- 这里只做复盘/工具改进时，不把它包装为已经完成了整片发布验收或零背景盲审；审查范围和未完成项目明确标注。

## Overview

**审片层审的是地图（脚本），本技能查的是领土（素材与成片）。**

整条管线在"提交视频平台生成"之前有十几道设计与审查，之后是零——但观众看的是成片，不是脚本。历史教训（《好》，2026-07）：脚本层设计 A 级、盲审理解度 85 分，成片却被观众普遍反馈"看不懂"——事后取证发现：全片唯一的名字焊点台词（"秀兰/哎，我在"）和唯一的关系锁定台词混音后 -38～-46dB 完全不可听（正常对白 -17～-25dB）、片尾真实故事卡被剪成"谢谢观看"、乱码信封特写照播。**这些全部发生在脚本之后，且全部可以被机械化检查拦住。**

三道闸门，对应生成后的三个时刻：

| 闸门 | 介入时机 | 输入 | 输出 |
|------|----------|------|------|
| **A 装配规范** | 分镜脚本定稿后、开始生成/剪辑前 | 平台分镜脚本 + 观众认知时间线（如有）+ 重构方案（如有） | `{标题}-装配规范.md` |
| **B 素材验收** | 每批片段生成后、进剪辑前 | 生成片段文件夹 + 分镜脚本（📌申报）+ 装配规范 | `{标题}-素材验收报告.md` |
| **C 成片体检 + 试映盲审** | 剪辑导出后、发布前（最后一关，有一票否决权） | 成片文件 + 装配规范 | `{标题}-成片体检报告.md` |

生成前先阅读对应模式的参考文件：

- `references/assembly-spec-template.md`：装配规范固定结构
- `references/clip-acceptance-rules.md`：素材验收六查与判定规则
- `references/film-check-protocol.md`：成片体检协议（已验证的 ffmpeg 配方、响度阈值、试映盲审流程、否决线）

## 模式 A：装配规范

剪辑/混音没有规范文档，就等于把全片命脉交给"剪辑时的手感"。从上游文档提取并锁定：

1. **必听台词清单**（核心）：凡承载枢纽信息或独立拍点的台词逐条入列——镜号、台词全文、挂靠的信息编号（I 编号）、为什么不可失。**枢纽信息所在的台词一条都不能漏进清单。**

2. **音轨归属表**（核心，与必听台词清单同级）：全片每一句人声逐条盖章，规则见 `narrative-info-planner/references/audio-lane-rules.md`。

   | # | 镜号 | 台词全文 | 🅐模型生成／🅑后期录制 | 时间窗 | 字数·语速·预算 | 提示词正文核对 |
   |---:|---|---|---|---|---|---|
   | 1 | 1→2 | "请不要在戏院食用——小小酥" | 🅑 后期录制 | 2.6–6.6（跨镜J-cut） | 11字+1破折号@3.3字/秒=4.0秒 ✅ | 正文无台词原文，已写"无人声、无画外配音" ✅ |

   三条硬要求：
   - **🅑 的句子，其原文不得出现在任何提示词正文里**；定稿前回分镜脚本逐块 grep `"` `“` `旁白` `广播` `画外音` `配音` `独白` 核对，命中即打回改分镜，不是"剪辑时静音就行"。
   - **每一句都要过时长预算**：`可容纳字数 ≈ (窗口秒数 − 0.4) × 语速`（快对白 5／正常对白 4.5／广告旁白 4／失真广播·强调句 3–3.5 字每秒；破折号省略号每处扣 0.3 秒、逗号扣 0.15 秒）。窗口 < 预算的，在装配规范阶段就要决定砍字、跨镜还是换字幕——**不许留给配音演员"念快点"**。
   - 必听台词清单里的每一条**默认都是 🅑**（需要精确入点与响度），除非它是画面内人物开口且已确认模型口型可用。
3. **字幕与卡字清单**：每条后期字幕/黑屏卡/片尾卡的完整文本 + 入出点 + 归属镜号。画面内不可生成文字的信息（信件、名牌、文件）一律走后期叠字并入列。
4. **禁删清单**：剪辑无论怎么压时长都不许动的项（片尾真实故事卡、名字焊点镜头等）。
5. **响度标准**：全片对白语音频段（200Hz-4kHz）目标 mean_volume -17～-25dB；任何必听台词与全片对白均值偏差 ≤6dB。
6. **逐镜剪辑要点**（可选）：剪入剪出建议、转场、音乐音效的叙事职能点（哪个音效在送信息，不许被配乐盖住）。

按 `references/assembly-spec-template.md` 输出。

## 模式 B：素材验收

生成的片段 ≠ 提示词写的画面。每条片段进剪辑前做**六查**（细则见 `references/clip-acceptance-rules.md`）：

1. **信息可见**：该镜 📌申报的信息增量在画面里真的发生了吗？枢纽事件必须以可见动作出现，白光/黑幕/只有反应镜 = 不合格。
2. **台词可听可辨**：🅐 镜的生成音轨里，台词能听清、内容正确（AI 常吞字改词）、口型对得上。
3. **误生成人声**：🅑 镜（音轨归属表标为后期录制）的生成音轨里**不该有任何人声**。听到模型自己配的话或嘟囔 = 提示词漏改，**该镜重生成**——不是"后期把音轨静音就行"：模型配音时会连带生成口型、说话表演和错误的动作节奏，画面本身已经被污染。
4. **文字乱码**：画面内出现的任何文字（信、屏幕、招牌）是否乱码/伪汉字——特写乱码 = 不合格。
5. **一致性**：角色脸型/服装/场景与参考图及相邻镜是否漂移。
6. **衔接**：与上一镜尾帧的空间、光线、道具状态接不接得上。

每条片段三种判定：✅合格 / 🔁重生成（附具体修法：改提示词哪一段/换哪张首帧）/ ⚠️降级使用（哪几秒可用 + 需要什么后期补救）。

## 模式 C：成片体检 + 试映盲审

**发布前最后一关，有一票否决权。** 两部分缺一不可（协议与命令见 `references/film-check-protocol.md`）：

**技术体检**（机械化，逐条测量，禁止"整体听感不错"）：

1. 全片语音频段响度扫描（15 秒窗口曲线）→ 标出所有可疑静默段；
2. 装配规范"必听台词清单"逐条定位 + 静听 + 测量，偏差 >6dB 或绝对值 <-35dB 判不可听；
3. 字幕完整性：抽帧对照字幕清单逐条核对在场与文本正确；
4. 禁删清单逐项确认在场；
5. 乱码/伪文字扫描（重点查特写镜头）。

**试映盲审**（模拟零背景观众第一遍观看）：

1. 抽帧（每 2-3 秒）+ **转写实际听得见的台词**（以实听和测量为准——禁止用剧本文本代替，那是信息泄漏，正是上次漏掉混音事故的原因）；
2. 交给零背景审读者（新会话 agent 或未接触项目的真人）做两轮复述：全信号版（帧+实听台词+字幕）与静音版（只给帧）；
3. 对照枢纽信息清单逐条判定：送达 / 缺失 / 误解。

**一票否决线**（触发任意一条，结论只能是"修复后复检"，禁止出现"基本没问题/可以发布"字样）：

- 任何一条必听台词不可听；
- 盲审复述在枢纽信息处断裂或误解；
- 禁删项缺失；
- 特写镜头出现乱码文字；
- 字幕清单缺漏 ≥2 条。

**降级模式**：若项目没有装配规范（老项目回溯体检），先从分镜脚本+认知时间线临时提取必听台词最小清单再体检——**不允许以"没有装配规范"为由跳过逐条静听**。

## 与其他技能的关系

- `storyboard-reviewer`：生成前的脚本层质检；本技能是生成后的素材/成片层质检。两者标准同源（枢纽信息、拍点、通道来自 narrative-info-planner 的产物），对象不同。
- `feedback-diagnoser`：观众反馈"看不懂/听不清"时，先查有没有成片体检报告——没有就先跑模式 C 降级体检，把"设计问题"和"执行失真"分开，再归因。
- `video-transition-auditor`：查的是生成**前**首尾帧与提示词的一致性；本技能模式 B 查的是生成**后**的实际产物。

## Output Rules

- 模式 A：`{标题}-装配规范.md`；模式 B：`{标题}-素材验收报告.md`；模式 C：`{标题}-成片体检报告.md`
- 三份文档都与项目文件放在同一目录
- 体检报告是只读诊断，修复后**重跑体检**产出复检报告，不改原报告

## Quality Bar

以下情况视为失败：

- 只跑技术体检不跑试映盲审，或反之
- 盲审由读过剧本/看过分镜的同一会话执行，却不标注可信度降级
- 把剧本台词文本直接喂给盲审者，代替"实际听得见的台词"转写
- 用"整体听起来没问题"替代必听台词逐条定位测量
- 触发否决线后仍给出发布建议或"瑕不掩瑜"式结论
- 体检对象是剪辑工程预览而不是最终导出的成片文件
- 素材验收只看首帧截图不听音轨
