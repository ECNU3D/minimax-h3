## 4. 服务、端口与启动档位

| 服务 | 地址 | 启动方式 |
|---|---|---|
| ComfyUI（生成服务） | `http://127.0.0.1:8188` | `start.ps1` / `start.cmd` / `start-1080p-sage.cmd`；停止用 `stop.ps1` |
| H3 导演台 | `http://127.0.0.1:8321` | `启动H3导演台.cmd` → `h3_director/start.ps1`（用 `.venv-cu130` 跑 `server.py`） |

**当前主力档位**（等价于双击 `start-1080p-sage.cmd`）：

```powershell
Set-Location 'C:\Users\shang\zheyu\minimax h3'
$env:PYTHONUTF8 = '1'
.\stop.ps1
.\start.ps1 -Cuda13 -SageAttention -KJNodes -VramHeadroom 8
```

实际下发的服务参数：`--listen 127.0.0.1 --port 8188 --disable-api-nodes --disable-all-custom-nodes --fast-disk --reserve-vram 2 --preview-method none`，再按开关追加 `--vram-headroom 8`、`--use-sage-attention`、`--whitelist-custom-nodes ComfyUI-KJNodes`。

- 只监听本机地址；默认关闭云端 API 节点与全部自定义节点，仅 KJNodes 走白名单。
- 服务已在运行时 `start.ps1` **不会**切换参数，必须先 `stop.ps1`；切换前先查 `http://127.0.0.1:8188/queue`。
- `-DisablePinnedMemory` 只加 `--disable-pinned-memory`，与旧 `-LowMemory`（同时禁 async offload 与 cuda malloc）不等价；它是待观察的缓解配置，不是已证实的卡死根治。
- 日志位置：`logs/comfy.stdout.log`、`logs/comfy.stderr.log`，PID 写在 `logs/comfy.pid`。

## 6. 当前默认生成配置

**参考图阶段**：FLUX.2 Klein 4B Distilled FP8，4 步 / CFG 1；复杂多图合成与单图修正改用 Klein Base 20 步 / CFG 5。

**视频阶段（三图参考，权威默认）**：三张独立参考直接进 H3，不抠图、不合成首帧、不加第四张。

| 引用 | 内容 | 尺寸 |
|---|---|---|
| `<Picture 1>` | 白底单人全身（身份与服装） | 768×1152 |
| `<Picture 2>` | 完整场景 | 1344×768 |
| `<Picture 3>` | 白底道具 | 1024×1024 |

节点链：`UNETLoader(ref2va int8_convrot)` + `CLIPLoader(qwen3vl_32b nvfp4)` + 视频/音频 VAE → `LoraLoaderModelOnly(ref2v turbo 4step)` → `MiniMaxH3MemoryEfficientSageAttentionPatch` → `MiniMaxLowVRAMAttention(head_chunks=4)` → `MiniMaxChunkFeedForward(chunks=8, seq_threshold=4096)` → `BasicGuider` + `RandomNoise` + `KSamplerSelect(res_multistep)` + `BasicScheduler(simple, steps=4, denoise=1.0)` → `SamplerCustomAdvanced` → `VAEDecode` / `VAEDecodeAudio` → `CreateVideo(fps=24)` → `SaveVideo(h264/mp4)`。

输出契约：**1344×768 原生分辨率、243 帧、24fps、10.125 秒**，无放大无裁切。
其他固定规则：视频宽高必须是 32 的倍数；帧数按 `seconds×24` 后补齐到 17 的倍数（10 秒 → 243 帧）；`head_chunks/ffn_chunks` 只是计算分块，**不是**把视频切成多段。

## 7. 生产入口、预算与停止协议

- **唯一视频提交入口**：`.venv-cu130\Scripts\python.exe scripts/h3_batch.py`（默认只做离线预检，加 `--execute` 才提交）；兼容包装为 [47ky_run_shots.ps1](../scripts/47ky_run_shots.ps1)。
- 镜头 spec 示例（仓库根解析路径，`name` 是逻辑镜头名，修订不改名）：

```json
[
  {
    "name": "ep01_s01",
    "prompt": "prompts/my-shot.txt",
    "refs": ["runs/my-refs/assets/character_front.png", "runs/my-refs/assets/scene.png", "runs/my-refs/assets/prop.png"],
    "seed": 20260916,
    "width": 1344,
    "height": 768,
    "seconds": 10
  }
]
```

- 现有 spec：[configs/](../configs) 下 13 个 `47ky-ep0X-sYY.json`，提示词在 [prompts/](../prompts) 下同名 `47ky-*.txt`。
- 预检强校验：`name` 合法且不重复；参考图**恰好三张**（历史镜头需显式 `--allow-reference-override`）；`<Picture n>` 标签集合与数量、顺序一致；尺寸为 32 的倍数；`0 < seconds ≤ 15`。
- 预算账本 `runs/h3-budgets/<campaign>/budget.json`（同 campaign 跨输出目录共用）：每镜最多 2 次总提交、每 campaign 累计 3 次执行失败即 STOP；进程锁 `.client.lock` 防并发客户端。
- 退出码语义：`0` 执行完成（不等于视觉接受）；`20` = STOP 终态，报告原因后结束本轮；`10` 兼容 PENDING，结束本轮并只查询原任务；`1` 输入/环境错误，先分类再决定。
- 图像阶段只补缺失资产：`scripts/reference_video_pipeline.py --until references`；图像、H3、TTS、SFX、音乐 GPU 阶段一律串行。
- 产物记录：每镜目录下 `inputs.json`（提示词/seed/参考 SHA256/尺寸/模型清单）、`server-preflight.json`、`job.json`（history 与产物哈希）、`result.json`（技术体检，视觉状态起始 `pending`）。
- 辅助脚本：`scripts/doctor.py [--hash]` 环境自检、`scripts/inspect_video.py` 逐帧解码与抽帧、`scripts/audit_h3_runs.py` 历史审计、`scripts/generate_image.py` 单图、`scripts/generate.py` 单独调试（非生产入口）。
- 生产约束同时写在 [.trae/rules/h3-production.md](../.trae/rules/h3-production.md) 与根 [AGENTS.md](../AGENTS.md)。

## 9. 边界与注意事项

- 本地开放的是 **H3-Base**；官方完整系统还含 H3-Context-IR 与 H3-Regenerate-2K 云端模块，不能把本地结果描述成完整官方 2K 系统。
- `manifest.status = success` 只代表执行完成，不代表画面被人工认可；视觉验收单独记录。
- 单镜成功不能外推为批量稳定：9/15–16 长批次出现过卡住与重复提交，因此才有预算与 STOP 协议；等待超时或结果不明时停止并先对账，不自动取消或重提服务端任务。
- 未验证：15 秒长视频、Base 20 步大分辨率、多任务并行、连续批量稳定性。
- 不改 ComfyUI / KJNodes 源码；模型下载走固定 revision + SHA256；量化格式必须真正下载对应权重。
- 根目录 `.env` 保存的是 LLM provider 配置（含 API key），本文件不记录其内容。
