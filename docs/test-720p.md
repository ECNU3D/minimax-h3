# 720p 本机测试与使用

测试日期：2026-09-11。RTX 5080 16GB + 32GB 内存，现有驱动和部署环境未更换。本机 H3 FP8 + NVFP4 文本编码器 + Turbo 8 步成功生成带音频的 5 秒和 10 秒 720p 视频。

[播放测试视频](../ComfyUI/output/video/h3_hd_00001_.mp4) · [逐秒画面](../ComfyUI/output/video/h3_hd_00001_.contact.jpg)

## 复现

在项目目录打开 PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
& .\.venv\Scripts\python.exe .\scripts\generate.py --width 1280 --height 736 --crop-720p --seconds 5 --name h3_hd
```

加 `--prompt-file .\prompt.txt` 可使用自己的提示词。输出保存到 `ComfyUI/output/video/`，同名前缀会自动编号。脚本保存的 `workflows/h3_hd_api.json` 是 API 工作流，不是带可视化布局的编辑器工作流。

模型宽高要求 32 对齐，720 不是 32 的倍数。因此先在 1280×736 上采样，经原生 ImageCrop 节点上下各裁 8 像素，再与音轨一起编码成 1280×720。没有放大低分辨率画面，也没有二次视频编码。`--crop-720p` 仅接受 `--width 1280 --height 736`，避免错误裁剪。构图时给上下边缘留少量余量。

| 参数 | FP8 FL2VA、Turbo LoRA 1.0、8 步、res_multistep / simple |
| 随机种子 | 20260910 |

| 整卡显存最高采样值 | 15,446 MiB（约 15.08 GiB） |
| 系统可用内存最低采样值 | 3.198 GiB |
| GPU 最高采样温度 | 69°C |
| 任务结果 | success，无 OOM，无解码失败 |

约每 5 秒采样一次，共 50 个样本；资源数字包含其他进程，不是模型精确分配峰值。这次重启了 ComfyUI，但不是清空操作系统文件缓存的标准冷启动基准。5 秒、10 秒各一次成功记录，尚未验证 15 秒、Base 20 步或连续批量任务的稳定性。

PyAV 完整解码 124 帧。逐秒画面显示橙色纸船向右漂移，水面涟漪和倒影变化，末段纸船靠近右侧边界。音轨解码为 165,888 个样本，RMS 0.005570、峰值 0.068774，数值有限且非静音；此检查不包含人耳音质、音效语义或音画同步主观评分。

## 10 秒补测

[播放 10 秒视频](../ComfyUI/output/video/h3_hd_10s_00001_.mp4) · [完整逐秒画面](../ComfyUI/output/video/h3_hd_10s_00001_.contact.jpg)

```powershell
& .\.venv\Scripts\python.exe .\scripts\generate.py --width 1280 --height 736 --crop-720p --seconds 10 --name h3_hd_10s
```

除时长外，使用与 5 秒测试相同的提示词、种子、分辨率、采样器和 8 步 Turbo 配置。帧数按模型规则对齐为 243，实际时长 10.125 秒。

| 项目 | 10 秒结果 |
|---|---|
| 输出 | 1280×720，243 帧，24fps，10.125 秒 |
| 服务端耗时 | 679.923 秒，约 11 分 20 秒 |
| 客户端检测完成 | 681.51 秒 |
| 文件大小 | 3,133,421 字节 |
| 音轨 | AAC，32kHz，双声道，324,608 个解码样本 |
| 整卡显存最高采样值 | 15,452MiB，约 15.09GiB |
| 系统可用内存最低采样值 | 3.212GiB |
| GPU 最高采样温度 | 69°C |
| 结果 | success，全部 243 帧及音轨解码通过，无 OOM |

本次约为 5 秒测试总耗时的 2.78 倍；这是两次实测比较，不能当作其他时长的固定换算公式。资源数据来自 136 次约 5 秒间隔采样。逐秒画面覆盖 0–10 秒，纸船由左向右移动、水面倒影和涟漪变化；开头纸船部分超出左侧边界，之后完整进入画面。音频信号非静音且有限，RMS 0.009083、峰值 0.109307；未做人耳主观评分。

## 使用与排错

- 此配置已通过 5 秒和 10 秒 720p 测试，分别约 4 分钟和 11 分钟。需要更快迭代时可沿用已测的 640×384 或 864×480，再以高清参数重新生成。
- 保持一次一个任务；本次显存已接近满载，避免同时启动其他 GPU 模型。不要根据本次结果直接推断长视频也能稳定完成。
- 若报 CUDA OOM，查看 `logs/comfy.stderr.log` 和任务 JSON；确认其他 GPU 任务结束后再重试同配置。若只在解码阶段失败，可进一步试分块 VAE 解码；这条恢复路径本次没有用到或验证。
- 若报系统内存不足，保留系统自动管理的分页文件并关闭占内存的程序。降低步数主要节省时间，不保证降低峰值显存。
- 若终端中断，先检查网页队列，避免重复提交。重启、环境修复和权重检查方法见 [部署手册](../README.md)。
