# H3 快速预览（独立可选档）

2026-10-13：用于快速看构图、人物/道具关系和动作意图。现有 `ref2v-768p-8step` 生产档不变。

## 选择

导演台已接入常规预览：在「分镜制作」列表上方的「视频生成模式」、自动制作窗口，或「分镜测试」右侧切换。默认仍为原来的 768p 高质量 / 8 步；快速预览固定 960×544 / 4 步，不启用 Sol-Attn。选择按项目或独立测试保存，只影响后续提交，队列快照、已有视频和预算不变。结果版本和任务记录标明实际模式。

分镜测试的高质量高级参数在切换期间保留。常规预览目前要求 1–9 张图片参考，不支持纯文本或音频参考；保留 MP4 原生音轨，不单独导出 FLAC。这些输入继续使用原有 768p 测试模式。预览后要正式出片，切回高质量并点击该镜「生成新版本」；自动批量制作仍只补缺少结果的镜头，不会覆盖已有预览。

- `ref2v-preview-4step`：960×544，官方 Ref2VA 4-step v0.1 LoRA，Euler/simple，视频/音频 shift 12/3。适合普通提示词预览。
- `ref2v-preview-sol-4step`：同上，额外开启内置 Sol-Attn，自适应 tau 1.3，从20%开始，保留参考/文本条件及目标音频精确计算。本机15秒片比常规预览少24秒，但出现伞消失又出现的连续性错误；保留为激进试验选项，不优先用于道具或精确动作判断。

本机实测：常规预览5秒片64.5秒、15秒片165.5秒；Sol分别62.9秒、141.5秒。当前优先推荐常规预览。均为单次测量，具体提示词与缓存状态会影响耗时。

两档都要求显式 `width: 960, height: 544`。24fps，5秒对应124帧，15秒对应362帧。保留三张独立参考和原生音轨，使用现有 INT8 模型及原有 VAE，不需要新下载。

视频生成依旧只走 `scripts/h3_batch.py`；预算、固定镜头名、预检和 STOP 规则见 [生产入口](h3-agent-production.md)。不要直接修改已提交 spec 的 profile 后恢复旧目录，应为同一镜头的下一次有预算试验使用新 run 目录、相同 campaign/name。

镜头 spec 示例（把 prompt、refs 改为实际文件）：

```json
[
  {
    "name": "shot_01",
    "prompt": "prompts/my-shot.txt",
    "refs": ["assets/character.png", "assets/scene.png", "assets/prop.png"],
    "seed": 20261013,
    "width": 960,
    "height": 544,
    "seconds": 5,
    "profile": "ref2v-preview-4step"
  }
]
```

本次测试配置：`configs/h3-preview-20261013-dense.json` 和 `configs/h3-preview-20261013-sol.json`。它们是固定试验记录，不作为无预算的重复出片按钮。

## 如何判断提示词

5秒预览适合看单一表情、构图或单一动作。原本写了15秒动作时间线的镜头，应保留15秒做低分辨率预览；不能直接压成5秒后判断后半段动作失败。

重点看人物数量、主体位置、道具是否出现、动作方向和事件顺序。人脸细节、手指、精细物理接触、最终音效与道具连续性，仍需高质量档再次检查。低分辨率、步数和注意力变化可能引入新问题；预览是筛查工具，不是对最终768p画面的承诺。
