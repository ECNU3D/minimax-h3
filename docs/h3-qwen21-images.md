# 导演台 Qwen Image 2.1 图片生成

2026-09-22：新建参考资产默认使用本地 Qwen Image 2.1。已有版本保持原模型记录，FLUX Klein 与 Codex Image Gen 仍可选择。

## 使用

1. 打开 `http://127.0.0.1:8321/` → 参考图 → 选择资产。
2. 本地模型选 **Qwen Image 2.1**。
3. **文生图**：填写提示词，生成新版本。
4. **参考图生图**：选择或上传 1–9 张有序参考。`上游资产 / 当前主图` 是动态依赖，批量制作时先生成上游，再使用本轮的新图。具体历史版本和上传输入是固定引用。
5. **选区改图**：选择一个固定历史版本或上传原图。用画笔涂抹、自由套索圈选，可用橡皮和撤销修正；点击“保存选区”，在提示词里描述修改，再生成。人物资产仍输出正、侧、背三张，局部编辑用于主图，侧背面从编辑后的主图派生。

选区编辑把原图和黑白蒙版依次交给 Qwen。生成后按原始分辨率合成，蒙版黑色区域保留原图像素，包括原图 alpha。边缘灰度是混合权重。蒙版、原图与实际生成结果分别保留 SHA256，原版本不覆盖。蒙版为空、尺寸不匹配、输入遭修改时拒绝提交。

批量重做：参考图 → 自动制作 → 图片模型 Qwen Image 2.1 → 勾选 **全部生成新版本（保留旧版）**。不勾选时仍只补齐缺失资产。该选项仅作用于图片批量任务，不能开启视频重做。

## 服务与生成记录

- 导演台：8321；Qwen：8190；现有 H3 / FLUX：8188，均只监听本机。
- Qwen 独立环境及权重沿用 [部署记录](qwen-image-21-local.md)。按需调用根目录 `start-qwen21.ps1`，不升级原 H3 环境。
- 两个生成服务共用显卡。导演台先检查另一服务队列；空闲时卸载其模型，有任务时停止本次提交，不中断其他任务。连接不明确时不自动重启。
- Qwen 图像入口：`scripts/qwen_image_pipeline.py`。默认 25 步、CFG 1、Euler / simple；人物 768×1152，场景 1344×768，道具 1024×1024；局部编辑保持原图尺寸。
- 2026-10-17 按用户批准删除了历史对照实验用的 `qwen3vl_8b_int8_convrot.safetensors`；当前 W4A8 编码器和生成模型/VAE 保留。历史脚本的 `--int8` 实验分支需要重新下载编码器后才能复跑，不能把主动清理视为默认依赖损坏。
- 每项结果保存在 `h3_director/data/runs/<job>/<asset>_v<attempt>/`。包含提示词、config、模型 revision、manifest、API/编辑器工作流、提交回执、任务 history、显存采样和输出哈希。局部改图另存原始模型输出及最终合成图。
- 不确定提交、丢失的任务和超时不自动重复提交。已完成步骤可在相同任务目录核对后恢复。

## 参考编辑纹理累积修复（2026-09-22）

本机复现了一个具体触发条件：用 Qwen 生成的图片继续编辑，且沿用生成该图的相同采样种子时，出现明显的斑驳背景、过度锐化和换装失败。父亲 R08→R09→R10 都设置为 20260917；母亲 R06→R07、少年 R03→R04 也重复种子。固定参考、提示词、40 步等其他参数，仅把编辑种子改为 918273645 后，父亲对照恢复干净且正确换装。这是本机观察，尚不能推断所有硬件/实现都如此。

新建导演台任务写入 `qwen_workflow_profile: independent-reference-seed-v2`：

- 文生图保持用户基础种子；参考图、侧背图和选区编辑使用 SHA256(工作流版本、基础种子、视图名、有序参考哈希、蒙版哈希) 派生的 63 位独立种子。
- 相同输入和基础种子仍可复现，参考顺序/内容、蒙版、视图变化会得到不同噪声。manifest 中 `requested_seed` 是基础种子，`seed` 是实际采样种子，API 工作流也记录实际值。
- 旧任务缺少 profile 时按 `legacy-v1` 恢复原始图，不能在原任务上偷偷更换采样。修复结果必须生成新版本。
- 保留 25 步、CFG 1、Euler/simple、W4A8 编码器、正常缓存。对照中单纯增加到 40 步、删掉颗粒词、CFG 2、关闭缓存/动态显存、更换 INT8 编码器、缩小参考、转 RGB、恢复 alpha、轻度模糊、FLUX VAE 重建都没有修复同种子问题，故没有把这些实验写入默认流程。
- 已经严重污染的中间图应回退到干净母图重建依赖链；正/侧/背仍分别从本角色正面派生，不串联侧面→背面。细节和身份一致性仍需人工检查。

对照、模型校验、逐项修复回执见 `runs/qwen21-cleanup-20260922/`。`scripts/qwen21_repair_characters.py` 是此次 11 个角色的有界图片修复脚本，逐项使用导演台任务、每项一次，无自动重试，不提交视频。

参考官方 [ComfyUI 编辑模板](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/image_qwen_image_2_1_image_edit.json)：25 步、CFG 1 是模板起始配置；官方完整管线通常使用更多步数。此处使用在本机验证的模板配置，不将快速测试等同于最高质量。
