# 独立分镜测试模块

入口：导演台左侧「分镜测试」，或 `http://127.0.0.1:8321/?view=lab`。

测试草稿、参考素材副本和运行记录存于 `h3_director/data/lab/<id>/`。不需要新建项目；从项目复制分镜时只读取源项目，复制参考图、提示词、种子及目标时长。后续项目变化不会改变测试输入，测试结果也不会覆盖项目已选视频。

## 使用

### 通用声音案例

编辑器新增「中文正文 / English」按钮，七组案例均有成对译文。切换同时替换当前显示/发送的主提示词、环境音和音乐；英文 section 名、角色编号、标签和中文台词保持一致。种子、时长、采样参数、参考素材、预算和历史结果不随切换改变。两版的手动修改分别保存，切回可恢复；不自动翻译手动改动，严格 A/B 对照前需同步两版语义。生成记录注明使用哪一版正文，旧记录不补猜语言。

新建通用案例默认中文。已有英文草稿保留其内容和修改，读取时补充模板的另一语言版本；不会覆盖旧草稿。自定义/项目导入草稿没有预置译文时，未提供的语言按钮禁用，可先应用双语通用案例。案例库本身也可中英预览。

页面上方提供七组独立案例：单人中文对白（8 秒）、双人问答（10 秒）、三人轮流对白（12 秒）、敲桌与放杯同步音效（8 秒）、雨声与树叶环境音（8 秒）、纯器乐钢琴（10 秒）、对白与配乐混合（10 秒）。每组包含完整场景、主提示词、环境音、配乐要求和试听检查项，不依赖项目素材。

「打开案例」复用已保存的草稿，保留用户修改；「新建副本」另建草稿。编辑器原来的「追加模板」已移除，改为「替换整套内容」：一起替换画面/对白、环境音、音乐、名称和时长，移除旧图像/音频参考绑定，保留种子、采样参数、笔记和当前预算。保存前可撤销。旧参考文件和历史任务仍然保留。

通用案例使用本机 ReferenceToVideo 原有的可选参考输入，只有实验室显式 override 路径允许 0–9 张图；仍然走 Ref2VA INT8 + 768p Turbo，不会因为没有图而切换成 FL2VA。项目生产的参考数量规则保持不变。纯文本案例已完成离线工作流验证，声音效果待实际生成试听。

前端实时检查、后端入队前检查明确的「写了中文台词但同时禁止对白/人声」及重复提示段落，发现后阻止预检/生成，允许保存草稿修正。这是基础文本检查，不能判断所有自然语言矛盾。音乐字段的 `no vocals` 不会被误判成禁止人物对白。

1. 新建空白测试并上传参考图，或选择来源项目与镜头，点击「复制到测试区」。
2. 在主提示词中编辑画面、对白、动作同步音效；在独立字段编辑 `overall_soundscape` 和 `non_diegetic_music`（无音乐可填 `N/A`）。参考图和可选参考音频编号分别从 1 开始，与提示词 `<Picture n>` / `<Audio n>` 标签对应。
3. 选择基线或对照预设。做 A/B 时保持种子、提示词和参考素材不变，每次只改一个参数。
4. 保存并「离线预检」，确认路径、素材哈希、参数和标签。点击「生成本次测试」才会使用 GPU。
5. 在「试听与对比」勾选最多两个结果。先听同一次生成的编码前 FLAC，再听 MP4 音轨；波形、采样率、声道、时长、峰值和 RMS 仅用于诊断，不能代替听音验收。每次结果提供参数快照、实际提示词、工作流、日志与文件下载，试听笔记随草稿保存。

## 原生声音工作流

`ref2v-lab` 独立于项目生产档位，固定 1344×768、INT8 Ref2VA、SageAttention、head chunks 4、FFN chunks 8、FP32 H3 音频 VAE、BasicGuider、simple scheduler。默认新版 768p Turbo LoRA、Euler 8 步、video shift 12、audio shift 3、denoise 1。

内置 audio shift 2.5 / 3 / 3.5 和无 Turbo 的 res_multistep 20 步对照。可编辑种子、时长、采样器、联合步数、两个 shift、denoise 和 Turbo 强度。音画联合采样，没有独立音频 CFG，也不伪造采样率。

同一个 `VAEDecodeAudio` 输出分别连接 `SaveAudioAdvanced(format=flac)` 和 `CreateVideo` → `SaveVideo`。保留编码前 PNG。最多 3 个参考音频通过 `LoadAudio` → `MiniMaxH3ReferenceToVideo.ref_audios.ref_audio_n` 接入，并连接同一音频 VAE。音频上传支持 WAV/FLAC/MP3/M4A/OGG，30 秒以内，单文件 40 MB 以内。

## 执行与恢复

测试任务和项目任务共用一个持久串行队列。生成仍仅调用 `scripts/h3_batch.py`，保持稳定逻辑镜头名 `shot`，每轮最多两次提交。改参数、提示词、种子不会自动刷新预算；每次输入、模型 manifest、参考哈希、工作流指纹及输出哈希都记录在独立运行目录。

两次用完后，用户可手动点击「开启新一轮测试」，旧预算与结果完整保留。存在待恢复任务或未对账的提交时不允许新开一轮。STOP 不自动恢复。服务重启后，任务保留原快照与目录，只允许恢复原任务对账。参考素材从草稿中移除不会删除历史任务依赖的文件。
